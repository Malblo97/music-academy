# SECTION 62 — LES EXERCICES DU MODULE 9 V1 (m09-e09 → e34, JSON complets, sans champs omis)

## Conventions du lot

**Le périmètre** : les 13 nouvelles leçons de genre (l05 → l17) portent chacune **deux exercices** dans leur footer — soit **26 exercices**, e09 à e34, qui complètent les 8 du lot MVP (e01–e08, §23.x). Le Module 9 atteint 17 leçons / 34 exercices.

**Le principe du lot, hérité du MVP** : chaque paire d'exercices matérialise les **deux gestes centraux** de sa leçon — l'un le mécanisme fondateur, l'autre la dramaturgie de scène. Les kinds se répartissent selon ce que le genre exige : `HARMONY_PROGRESSION` quand la grammaire porte, `MELODY_COMPOSE` quand la ligne porte, `ARRANGEMENT` quand l'assemblage porte (le kind du M9 MVP, §23.x), `LAYERING` pour l'horreur et la SF (les genres où `sound_design` pèse plus que l'harmonie — M6 en résidence), `ORCHESTRATE` en format `Part[]` quand le casting porte (M7 en résidence), et `DAW_MISSION` pour l'animation (le genre où le travail est technique : M10 en résidence).

**Décisions de spec du lot** :
1. Les profils de genre nouveaux entrent dans la matrice §7.8 : `horror`, `fantasy`, `sci-fi`, `drama`, `comedy`, `animation`, `western` (déjà calibré par m11-e06), `period`, `action`, `adventure`, `war`, `superhero`, `minimalism` ;
2. Clés de contraintes nouvelles, toutes des paramétrages de checkers existants : `consonanceInvestment` (le ratio consonant/dissonant et le contraste), `stingerPolicy` (un par séquence, jamais périodique), `pulseForbidden`, `unevenEntryIntervals`, `thresholdMediant`, `humanScaleFirst`, `feerieBudget`, `threeVersionsTest`, `stateTransitions` (la forme par états), `oneHumanLayer`, `subtextLevel` (le cran en dessous), `notesPerMinuteMax`, `singlePeakPerFilm`, `deadpanReturn`, `silenceAsPunchline`, `hitMap` (le croisement tempo×timecode de M10, en régime animation), `gestureLexicon`, `openFifthRatio`, `groundElements` (trois éléments maximum), `passacagliaGround`, `periodMarkerCount`, `riffRequired`, `breathRequired` (la respiration obligatoire), `relaunchLadder`, `whistleTest`, `secondThemeRequired`, `fourBarsOfLyric`, `lamentBass`, `lateInEarlyOut`, `emblemKit` (le jeu complet de variantes), `withheldTheme`, `additiveProcess`, `cutPoints`, `voiceBandClear`.

**La structure en paires tient partout** : chaque leçon reçoit son exercice de *mécanisme* (le vocabulaire, la grammaire, l'objet transformable) et son exercice de *dramaturgie* (la scène type de la §5 de chaque leçon, avec sa courbe). Les deux se chaînent par `sourceSubmission` dans dix cas (e16←e15, e20←e19, e26←e25, e28←e27, e30←e29, e32←e31, e34←e33), reproduisant le geste du métier : on forge l'outil, puis on l'emploie en situation.

**Les six lois transversales du module sont chacune en checker** — et c'est le fil rouge du lot :

| La loi | Le genre qui la porte | Le checker |
|---|---|---|
| L'échelle humaine avant le surhumain | fantasy, SF, super-héros | `humanScaleFirst`, `oneHumanLayer`, `humanLayerInEveryCue` |
| Le budget se garde pour un seul sommet | drame, super-héros, aventure | `singlePeakPerFilm`, `withheldTheme` |
| Le silence est un instrument | horreur, comédie, western, guerre | `silenceAsPunchline`, `totalSilenceBeforeEnd`, `silenceAfterStinger` |
| L'intensité constante est une intensité faible | action, horreur | `breathRequired`, `consonanceInvestment` |
| Le médium appartient à la voix | comédie, animation, documentaire, action | `voiceBandClear` (rule `orch.masking`) |
| On ne résout pas ce qui ne se résout pas | SF, fantasy, drame, guerre, minimalisme | `forbiddenCadences`, `endsUnresolved` |
