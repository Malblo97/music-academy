# SECTION 41 — MODULE 3, LEÇONS 4–6 : LES PASSAGES SECRETS

## 41.1 LEÇON m03-l04 — « Le dim7 pivot : l'accord aux quatre visages »

```mdx
---
id: m03-l04-dim7-pivot
module: module-03-harmonie-avancee
title: "Le dim7 pivot : l'accord aux quatre visages"
estMinutes: 25
skills: { harmony: 1.0 }
---
```

### Pourquoi revenir sur un accord que tu connais

Le dim7 de l13/l23 M1 était un outil local : le vii°7 qui mène, l'apesanteur inquiète du thriller (m09-l04). Cette leçon révèle sa propriété structurelle — celle qui en fait la **deuxième gare de correspondance** après la Ger⁶ (l03 §3) : le dim7 est un accord **parfaitement symétrique**, et la symétrie a une conséquence vertigineuse : il n'appartient à personne, donc il appartient à tout le monde.

### 1. La symétrie : l'accord qui n'a pas de fondamentale

Le dim7 empile des tierces mineures : 3+3+3+3 = 12 — l'octave exactement. Conséquence : **chacune de ses quatre notes peut être la fondamentale** ; renversé, il reste identique à lui-même (transpose B–D–F–A♭ d'une tierce mineure : D–F–A♭–B — les mêmes notes). Il n'existe donc que **trois accords dim7 dans tout le système** (B°7, C°7, C♯°7 — le quatrième, D°7, redonne les notes de B°7) :

```
Les 12 pitch-classes, partagées en 3 dim7 :
  {B, D, F, Ab}   {C, Eb, F#, A}   {C#, E, G, Bb}
Trois objets couvrent tout le chromatisme — la première structure
SYMÉTRIQUE de ton parcours : l'octatonique (l12) et la gamme par tons
(l11) sont ses cousines, et elles poseront le même vertige : quand
rien ne distingue les notes, rien ne désigne la tonique.
```

### 2. Les quatre visages : un accord, quatre dominantes

Le vii°7 de M1 fonctionne parce qu'il contient la sensible qui monte. Mais puisque **chaque note du dim7 peut jouer la sensible**, le même accord est le vii°7 de quatre toniques :

<MusicExample id="quatre-visages" title="B–D–F–A♭ : quatre sorties (joue les quatre !)">
  A) [B2+D4+F4+Ab4]:h → [C3+C4+E4+G4]:h      — B sensible : → DO (M/m)
  B) [D3+B3+F4+Ab4]:h → [Eb3+Bb3+Eb4+G4]:h   — D sensible : → MI♭
  C) [F3+B3+D4+Ab4]:h → [Gb3+Bb3+Db4+Gb4]:h  — F sensible : → SOL♭
  D) [Ab2+B3+D4+F4]:h → [A2+C4+E4+A4]:h      — A♭≡G♯ sensible : → LA
  Quatre toniques à une tierce mineure d'écart : DO, MI♭, SOL♭, LA —
  le même accord ouvre quatre portes réparties symétriquement sur le
  cycle. (Note l'orthographe : le A♭ devient G♯ pour la sortie D —
  l'enharmonie est le mécanisme, pas un accident : F-6 encore.)
</MusicExample>

C'est le **rond-point harmonique** : entre dans le dim7 depuis n'importe quelle tonalité, tourne (il est identique sous rotation), sors par la porte de ton choix — DO, MI♭, SOL♭ ou LA, majeur ou mineur (huit destinations réelles). Aucun autre accord de quatre sons n'offre ça.

### 3. Les trois métiers du dim7 (le local, le passant, le pivot)

| Métier | Mécanique | Territoire |
|---|---|---|
| **Le meneur local** (M1, rappel) | vii°7 → I : la tenaille sur la tonique | la cadence intensifiée, le gothique |
| **Le passant chromatique** | ♯i°7, ♯ii°7… entre deux accords diatoniques : la basse chromatique harmonisée (C → **C♯°7** → Dm : chaque note du dim7 glisse d'un demi-ton vers sa cible) | LA cheville du jazz et de la comédie musicale — l'escalier doré |
| **Le pivot modulant** | entrer par un visage, sortir par un autre (§2) — souvent avec le **frisson du trémolo tenu** : le dim7 qui tremble pendant que le monde bascule | le mélodrame, l'horreur classique, la bascule de scène — la l05 le systématise |

Le passant mérite sa conduite (l'analyseur le tague `dim7-passing` : dim7 dont TOUTES les voix résolvent par demi-ton ou note commune, entre deux accords à fonction claire) :

<MusicExample id="escalier-dore" title="Le passant : la basse qui monte l'escalier (do majeur)">
  [C3+E4+G4+C5]:h [C#3+E4+G4+Bb4]:h | [D3+F4+A4+D5]:h [D#3+F#4+A4+C5]:h | [E3+E4+G4+C5]:w
  I → ♯i°7 → ii → ♯ii°7 → I⁶ : la basse C–C♯–D–D♯–E, chaque dim7
  glissant vers son voisin. Compare avec la version nue (I–ii–I⁶) :
  le même trajet, sans les marches dorées.
</MusicExample>

### 4. Le coût (la mise en garde d'usage)

Le dim7 est l'accord le plus « connoté » du répertoire : sur-employé par un siècle de mélodrame et de cinéma muet, il vire vite au pastiche (le trémolo de dim7 = la moustache du méchant). Les règles de dosage : **en fonctionnel, le passant passe inaperçu** (il est conduit, bref, au service de la basse) ; **le pivot est un événement** (un par pièce) ; **le dim7 tenu-exposé est une citation** — assume le second degré ou choisis l'octatonique (l12), sa version moderne et dé-connotée.

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Chercher LA fondamentale du dim7 | l'analyse qui tourne en rond | il n'en a pas : nomme-le par sa sensible ACTIVE (celle qui résout) |
| Le passant qui saute | l'escalier cassé | toutes les voix par demi-ton ou note commune — c'est sa définition |
| Le pivot sans préparation d'oreille | la sortie surprise qui sonne fausse | tenir le dim7 (le temps que l'oreille lâche l'ancien monde), PUIS sortir |
| Le trémolo de dim7 premier degré | la moustache du méchant | citation assumée, ou octatonique |

### La mission (m03-e04, HARMONY_PROGRESSION)

12 mesures en do majeur, les trois métiers dans l'ordre : une phrase avec **passant** (♯i°7 ou ♯ii°7, conduite d'escalier vérifiée), une cadence intensifiée par **vii°7**, puis le **pivot** : le dim7 tenu une ronde (trémolo mental), sortie vers MI♭ majeur, cadence de confirmation (F-5 s'applique). `requireIdiom: ["dim7-passing","dim7-pivot"]`, `modulationCheck` C→E♭.

- [ ] 3+3+3+3 : trois dim7 couvrent le chromatisme — l'accord sans fondamentale
- [ ] Quatre sensibles possibles = huit destinations : le rond-point
- [ ] Trois métiers : le meneur, le passant (l'escalier), le pivot (la gare)
- [ ] Le dim7 exposé est une citation — le doser ou l'octatoniser

## 41.2 LEÇON m03-l05 — « La modulation enharmonique : les passages secrets »

```mdx
---
id: m03-l05-enharmonie
module: module-03-harmonie-avancee
title: "La modulation enharmonique : les passages secrets"
estMinutes: 30
skills: { harmony: 1.0 }
---
```

### Pourquoi « secrets »

La modulation par pivot de l23 M1 voyage entre voisines (les tonalités qui partagent des accords). Mais comment rejoindre une tonalité **lointaine** — do → la bémol mineur, six bémols plus loin — sans le fondu enchaîné brutal du gear change ? Réponse : par les accords qui ont **deux orthographes** — le même son, deux noms, deux mondes. L'auditeur entre dans l'accord par une porte et en sort par une autre qu'il n'avait pas vue : le passage secret. Tu possèdes déjà les deux clés (Ger⁶≡V7 en l03, le dim7 en l04) ; cette leçon en fait un système — et ajoute la troisième clé.

### 1. Le principe (et pourquoi ça marche)

```
1. ARRIVER sur l'accord-passage dans le monde A (il y a un sens clair)
2. LE TENIR — le temps que l'oreille perde ses repères : l'accord
   symétrique/ambigu, isolé, ne dit plus d'où il vient
3. LE RÉSOUDRE selon son AUTRE lecture : le monde B s'ouvre
4. CONFIRMER (la cadence du nouveau monde — la loi de l23 M1/F-5,
   toujours elle : pas de confirmation, pas de modulation)
```

Ça marche parce que l'oreille ne lit pas l'orthographe : elle lit des pitch-classes et des **résolutions** (le moteur du produit fait pareil — F-6 n'était pas une limite, c'était la vérité perceptive). L'accord enharmonique est un mot qui change de sens selon la phrase qui le suit.

### 2. Les trois clés du trousseau

| Clé | Les deux lectures | Destinations | Caractère du passage |
|---|---|---|---|
| **Ger⁶ ≡ V7** (l03) | Ger⁶ de A ↔ V7 de B (B = un demi-ton sous A... précisément : le V7 sur la même basse vise la tonalité un TRITON plus loin que le V visé par la Ger⁶) | 1 destination par sens, à distance lointaine fixe | le velours : deux accords riches, la couture est douce — LE passage du romantisme |
| **dim7** (l04) | 4 sensibles possibles | 8 destinations (4 toniques × M/m), tierces mineures | le frisson : le rond-point dramatique |
| **L'accord augmenté** (la 3e clé) | 4+4+4 : la DEUXIÈME structure symétrique — trois notes, chacune peut être la fondamentale d'un accord augmenté... et surtout : chaque note peut monter OU descendre d'un demi-ton vers une triade M/m | 6 destinations usuelles, tierces MAJEURES | l'étrange lumineux : le passage de la SF et du rêve (et l'aïeul de la gamme par tons, l11 — les symétries se tiennent toutes) |

<MusicExample id="passage-allemand" title="Le passage Ger⁶↔V7 dans les deux sens">
  A) DO → RÉ♭ (le V7 devient Ger⁶) :
  [C3+E4+G4+C5]:h [F3+A3+C4+Eb4]:h~ | [F3+A3+C4+Eb4→D#4]:h [E3+G#3+B3+E4]:h | [A2+A3+C#4+E4]:w
  … arrivé comme F7 (V7/♭... comme dominante secondaire en préparation),
  tenu, résolu en Ger⁶ de LA : le E♭ « devient » D♯, la basse s'écarte
  F→E. Confirme en la, et DO → LA est franchi par le velours.
  B) L'inverse : compose une Ger⁶ dans ton monde… et résous-la en V7
  (quinte descendante) : te voilà un triton plus loin que prévu.
</MusicExample>

*(L'orthographe E♭→D♯ dans l'exemple est pédagogique : à l'oreille et pour le moteur, rien ne change à l'accord — tout change à sa sortie.)*

### 3. La dramaturgie du passage secret

Le passage enharmonique n'est pas un utilitaire : c'est un **effet de mise en scène** — le sol qui se dérobe élégamment. Ses territoires :

- **la révélation** : ce que le personnage croyait (monde A) n'était pas la vérité (monde B) — l'accord-passage EST le moment où il comprend ;
- **le rêve/la bascule de réalité** : l'augmenté surtout (la SF de m02-l13 gagne son mécanisme harmonique) ;
- **le voyage express** : atteindre en deux accords une tonalité qu'un pivot diatonique mettrait huit mesures à rejoindre — l'outil des développements denses.

Et sa loi de dosage, cohérente avec tout le module : un passage secret **par pièce** est un coup de théâtre ; trois en font un tour de passe-passe (l'auditeur cesse de croire au sol, donc plus rien ne se dérobe).

### 4. Le moteur et les passages (ce que le produit vérifie)

`modulationCheck` (§19.4) gagne un mode `enharmonic` : détection de l'accord-passage (pitch-classes ∈ {dim7, aug, Ger⁶/V7}), vérification de la double lecture (la fonction d'ARRIVÉE dans le monde A ≠ la fonction de SORTIE dans le monde B), tenue minimale (≥ 2 temps — le §1.2), et confirmation cadentielle en B (F-5). Le rapport nomme les deux lectures : « ton F7, arrivé en dominante de B♭, ressort en sixte allemande de la — le passage est propre ».

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Sortir sans avoir tenu | le passage escamoté : ça sonne comme une faute | 2 temps minimum d'ambiguïté — l'oreille doit lâcher prise |
| Le passage sans confirmation | l'auditeur n'est jamais ARRIVÉ | la cadence du monde B, toujours (l23/F-5) |
| Trois passages par pièce | le tour de passe-passe | un coup de théâtre par pièce |
| Choisir la clé au hasard | le caractère du passage contredit la scène | velours=Ger⁶ ; frisson=dim7 ; étrange=augmenté |

### La mission (m03-e05, HARMONY_PROGRESSION)

Le voyage lointain : 14 mesures, DO majeur → LA majeur (une tierce mineure sous... une tierce majeure au-dessus — bref : une destination non-voisine) par le passage de ton choix parmi les trois clés (variantes : `ger6-v7` / `dim7` / `augmented` — chacune avec ses contraintes de conduite), établissement A, passage tenu, confirmation B, puis la reprise du thème initial DANS le monde B (la révélation : le même matériau, l'autre vérité — `samePitchSequenceAsGiven` transposé sur la fenêtre finale). `modulationCheck: { mode: "enharmonic" }`.

- [ ] Le passage : arriver-A, tenir, sortir-B, confirmer
- [ ] Trois clés : Ger⁶↔V7 (velours), dim7 (frisson), augmenté (étrange)
- [ ] L'oreille lit les résolutions, pas l'orthographe — F-6 était une vérité perceptive
- [ ] Un coup de théâtre par pièce

## 41.3 LEÇON m03-l06 — « Les médiantes systématisées : la table des huit mondes »

```mdx
---
id: m03-l06-mediantes
module: module-03-harmonie-avancee
title: "Les médiantes systématisées : la table des huit mondes"
estMinutes: 25
skills: { harmony: 1.0 }
---
```

### Pourquoi finir le romantisme tardif par les médiantes

l24 M1 t'a donné le geste (C→A♭, C→E : la bascule de monde, le fil de la note commune) ; cette leçon donne le **système** : depuis n'importe quelle triade majeure, il existe exactement **huit triades à une tierce** — quatre racines (♭3̂, 3̂ en dessous ; ♭6̂... reprenons proprement : tierce mineure ou majeure, au-dessus ou en dessous), chacune en majeur ou mineur. Huit mondes voisins-lointains, chacun avec sa couleur propre — la palette complète du cinéma de merveille et d'ombre.

### 1. La table (depuis DO majeur — transpose-la partout)

| Cible | Distance | Notes communes avec C (C–E–G) | Couleur (le caractère du saut) | Tag |
|---|---|---|---|---|
| **E majeur** | 3ce M ↑ | E | l'émerveillement, la porte des étoiles (l24) | chromatique |
| **E mineur** | 3ce M ↑ | E, G (2 !) | le voisin doux — diatonique (iii) : à peine un saut | diatonique |
| **E♭ majeur** | 3ce m ↑ | G | l'héroïque soudain, l'éclat de côté | chromatique |
| **E♭ mineur** | 3ce m ↑ | aucune | le gouffre — la plus étrangère des huit | disjointe |
| **A majeur** | 3ce m ↓ | E | la chaleur qui s'ouvre, la nostalgie dorée | chromatique |
| **A mineur** | 3ce m ↓ | E, C (2) | le voisin sombre — diatonique (vi) : la rompue de l16 | diatonique |
| **A♭ majeur** | 3ce M ↓ | C | la gravité solennelle, l'ombre majestueuse (l24) | chromatique |
| **A♭ mineur** | 3ce M ↓ | C≡ (via E♭... la tierce C reste) | l'abîme velouté | disjointe |

Trois lectures de la table :

```
LE GRADIENT D'ÉTRANGETÉ : 2 notes communes (Em, Am : les médiantes
  DIATONIQUES — tu les connais depuis M1) → 1 note (les quatre
  CHROMATIQUES : le grand frisson contrôlé — E, E♭, A, A♭ majeurs)
  → 0 note (les DISJOINTES : le saut dans le vide)
LA BOUSSOLE ÉMOTIONNELLE : vers le HAUT = la lumière qui monte
  (E=étoiles, E♭=héroïsme) ; vers le BAS = la profondeur (A=chaleur,
  A♭=solennité) — et le mineur assombrit chaque direction
LE FIL (l24, confirmé en système) : chaque médiante à 1-2 notes
  communes se coud par sa note tenue DANS LA MÊME VOIX (F-7 : le
  crédit plein exige la voix, pas la pitch-class) ; les disjointes
  n'ont PAS de fil — leur brutalité est leur sens
```

### 2. Les chaînes : quand les médiantes deviennent un voyage

Une médiante est une bascule ; une **chaîne** de médiantes est un vertige organisé. Deux architectures :

| Chaîne | Trajet | Propriété |
|---|---|---|
| **Le cycle de tierces majeures** | C → E → A♭ → C | trois sauts, retour au départ (4+4+4=12 : la symétrie de l'augmenté, l05 §2 — tout se tient) : la boucle d'apesanteur qui ne va nulle part et c'est le but (m01-s46 en était une !) |
| **Le cycle de tierces mineures** | C → E♭ → G♭ → A → C | quatre sauts, retour (3+3+3+3 : la symétrie du dim7, l04) : plus serré, plus inquiet — l'escalier du thriller cosmique |

La loi des chaînes : **le fil change de note à chaque maillon** (C→E tient E... — vérifions : C–E–G → E–G♯–B tient E ; E→A♭ tient... G♯≡A♭ ; A♭→C tient C) — la couture voyage dans les voix : écris-la voix par voix (c'est un exercice de conduite autant que de couleur), et le moteur suit chaque maillon (`commonToneThread` par bascule, F-7).

### 3. Médiantes et fonction : les trois régimes d'emploi

La médiante chromatique peut vivre dans les trois systèmes de la carte (l01) — c'est sa souplesse unique :

```
RÉGIME FONCTIONNEL : la médiante comme ÉVÉNEMENT dans un monde tonal —
  un saut, un retour (C → A♭ → G7 → C : l'ombre traversée, la fonction
  reprend ses droits) ; le régime de l24 M1
RÉGIME MODAL/COLORISTE : les médiantes comme SEUL principe de
  circulation — plus de dominante du tout, les mondes s'enchaînent par
  tierces et fils (le régime des chaînes : forbidFunctionalCadence
  s'active — première apparition de la contrainte, le système 3 approche)
RÉGIME PIVOT : la médiante comme porte de modulation confirmée
  (C → E établi-confirmé : le nouveau monde est HABITÉ, pas visité —
  la frontière de l23 M1, appliquée aux tierces)
```

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Toutes les médiantes traitées pareil | huit sauts, une seule couleur perçue | la table : chaque cible a SON caractère — choisis au brief |
| Le fil dans des voix différentes | la couture qui ne s'entend qu'à moitié | la note commune tenue dans LA MÊME voix (F-7) |
| La chaîne qui cadence en route | le vertige interrompu par la grammaire | en régime coloriste, la dominante est bannie — assume le régime |
| La disjointe « adoucie » | E♭m approché par un fil qui n'existe pas | la disjointe est brutale par nature : c'est son emploi |

### La mission (m03-e06, HARMONY_PROGRESSION à variantes)

Deux variantes au choix : **(a) « la traversée »** — régime fonctionnel : do majeur, une phrase qui visite DEUX médiantes contrastées de la table (une lumineuse, une sombre — déclare tes choix), fils vérifiés, retour cadencé ; **(b) « la boucle »** — régime coloriste : le cycle complet de tierces majeures (C→E→A♭→C, 12 mesures), fils voix à voix à chaque maillon, `forbidFunctionalCadence` actif (aucun V→I nulle part), et l'atterrissage final par le fil seul. Les huit couleurs de la table en `authorNotes` du rapport : le moteur nomme chaque saut par sa ligne de table.

- [ ] Huit mondes à une tierce : le gradient d'étrangeté (2-1-0 notes communes)
- [ ] La boussole : haut=lumière, bas=profondeur, mineur=ombre
- [ ] Les chaînes bouclent par symétrie (4+4+4, 3+3+3+3) — le fil voyage de voix en voix
- [ ] Trois régimes : l'événement, le principe, la porte
