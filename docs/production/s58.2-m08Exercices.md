# SECTION 58.2 — LES EXERCICES DU MODULE 8 (m08-e01 → e15, JSON complets, sans champs omis)

## Conventions du lot

**Le profil `jazz`** (§7.8) attendait ce module : `harmony.unresolved-seventh` en veille, `melody.out-of-key` relâchée (le chromatisme est la grammaire), la fenêtre de syncope 0.35–0.7. Il est le défaut du lot ; `swingTarget` s'y ajoute par exercice.

**Décisions de spec du lot** (à répercuter dans `@ma/shared`) :
1. **`swingTarget: [min, max]`** — le jumeau jazz de `syncopationTarget`, alimenté par la nouvelle métrique `swingRatio` de `rhythmProfile` (ratio mesuré sur les paires de croches). Se déclare **par part** quand la pulsation doit rester droite (la walking à ~1.0 sous une ligne à 2.0) ;
2. **`chordScaleCheck`** — la contrainte reine : chaque note évaluée contre la gamme de l'accord courant, avec la nuance d'origine (hors-gamme = signalé ; avoid note *posée* = suggestion ; avoid note *passante* = silence). Modes `horizontal` (la tonalité pense) / `vertical` (l'accord pense) / `mixed` ;
3. **Idiomes tagués** : `walking-bass`, `enclosure`, `shell-voicing`, `rootless-voicing`, `blues-scale`, `turnaround`, `back-door`, `bebop-scale`, `planing` (réutilisé en détection de bloc big band) ;
4. Clés de contraintes nouvelles : `accentOnOffbeats`, `anticipations`, `laidBackDeclared`, `voicingZone`, `voicingFormAlternation`, `smoothnessMaxPerVoice`, `cellTagging`, `bluesForm`, `callResponseAAB`, `holesRatioMin`, `bendedBlueNotes`, `beatTargets` (cible/chemin/approche), `chromaticApproaches`, `patternVariety`, `registerArch`, `avoidNotesPassingOnly`, `chiaroscuro` (l'altération exposée puis résolue), `interpolatedChords`, `spreadVoicings`, `lineCliche`, `delayedCadence`, `fills`, `reharmMethod` (piliers, intention, techniques), `structuralNotesCovered`, `changedChordsRatio`, `pillarsCommon`, `chorusArc`, `densityPerChorus`, `modalDramatization`, `inOutExcursion`, `vampInvariant`, `thickenedLine`, `leadVoiceIsTheme`, `dropVoicing`, `sectionCallResponse`, `kicks`, `shoutChorus`, `compingRules`, `composedInteraction`, `almostTogether`, `markerCount` (le compteur de signaux par distance), `distanceDeclared`, `aabaForm`, `bridgeDeparture`.
