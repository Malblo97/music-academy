# SECTION 83.3 — MODULE 11 : LES 8 QUIZ EN JSON COMPLET

**Périmètre.** La tranche §83.2 avait livré les quiz M11 au **format abrégé** (Q / options / why en ligne). Cette section les rédige au **format JSON définitif** de la charte (celui de `m02-l01-quiz`), prêt à coller dans le contenu.

**Comptes conformes sans rééquilibrage** : l01→l07 = 5 chacun · l08 = 7 = **42 items** — la tranche abrégée était déjà alignée sur les footers.

**Deux corrections de contenu** (les leçons font foi) :
- **l02** : les trois régimes de leitmotiv sont *le thème-étiquette · le thème-récit · le tissu de motifs* (§3) — §83.2 proposait « thème-décor / thème-signal », qui n'existent pas dans la leçon et perdent le troisième régime, celui où les thèmes se rencontrent dans l'orchestre quand les personnages se rencontrent à l'écran ;
- **l05** : les quatre indices de frontière sont *la cadence · le changement d'effectif · le changement de matériau · le changement de système ou de tonalité* (§1), classés par force décroissante — §83.2 citait « registre + silence », qui n'en font pas partie.

**Un item ajouté là où il manquait** : §83.2 ne portait **aucun ▶ pour l06**. Le contre-exemple western (la pièce qui viole le trot et reste western) est précisément un point qui s'entend — il devient l'item jouable du quiz, et la question du **test du retrait** y gagne sa démonstration.

**Format des items ▶ : trois espèces, propres à un module d'analyse.**
- **`play`** (2 items) quand le matériau se rend en notation : la bascule de système (l03) et le contre-exemple de genre (l06) sont des affaires de notes et de mode ;
- **`playAsset`** (5 items) quand l'objet analysé est orchestral ou produit : les pièces du corpus interne sont les assets eux-mêmes — Elena, les deux « Remise », la reconstruction, le vol légal ;
- **`capture`** (1 item) pour l01 : la superposition de **ta courbe de tension et de celle du moteur** est une image, pas un son — c'est l'exercice signature du module, et il se montre.
