### Pourquoi le compositeur touche à l'audio

Ton monde est le MIDI — mais l'audio entre dans ta session par quatre portes : la **voix enregistrée** (le chanteur, la voix parlée à traiter), les **maquettes reçues** (le thème fredonné du réalisateur dans son téléphone — un classique absolu), tes **rendus** (l10), et les **samples** (Module 6). Cette leçon couvre le kit audio du compositeur : pas l'ingénierie — les quatre gestes qui débloquent les quatre portes.

### 1. Le Musical Mode : l'audio qui suit le tempo

Le rendez-vous de l11 §3 : l'audio vit en secondes, ta grille en mesures élastiques. Le **Musical Mode** (dans la Sample Editor ou la Pool) rend l'événement audio *élastique* : il suit désormais la Tempo Track comme le fait le MIDI.

```
Le geste :  ouvre l'audio dans le Sample Editor → vérifie le tempo
            DÉTECTÉ (corrige-le si Cubase s'est trompé : c'est fréquent
            sur les boucles courtes) → coche Musical Mode
Le test :   change le tempo du projet : l'audio suit ? c'est bon.
Le prix :   l'étirement a un coût sonore (l'algorithme choisi dans la
            Pool : élastique ≠ gratuit) — au-delà de ±10 %, ça s'entend ;
            au-delà de ±20 %, ça se dégrade franchement
```

Doctrine : Musical Mode **ON** pour tout audio qui doit vivre dans la grille (boucles, rendus retravaillés, maquettes à caler) ; **OFF** pour ce qui vit en secondes (la voix synchronisée à l'image, les ambiances).

### 2. VariAudio : le MIDI caché dans l'audio

VariAudio (Sample Editor, onglet dédié) analyse un audio **monophonique** — une voix, un instrument seul — et le transforme en segments éditables : chaque note détectée devient un bloc qu'on peut déplacer en hauteur, redresser, étirer. Deux métiers pour toi :

| Métier | Le geste | La limite honnête |
|---|---|---|
| **La correction discrète** | la note de la chanteuse à 30 cents près : tu la recentres (Pitch Snap partiel — jamais 100 % : la justesse parfaite sonne morte, c'est le CC1 plat de l'intonation) | monophonique seulement ; les corrections > 1 ton s'entendent |
| **L'extraction de MIDI** | *Extract MIDI* : la maquette fredonnée du réalisateur devient une piste MIDI — son thème dans TON Key Editor, analysable, harmonisable… et soumissible au produit (le Melody Practice analyse le thème du réal : la boucle la plus inattendue du workflow) | la détection se relit note à note — le fredon est approximatif, l'extraction aussi : c'est un brouillon fidèle, pas une partition |

### 3. Les gestes d'édition audio de survie

Le reste du kit, en quatre gestes : le **fade** par les poignées d'événement (jamais de clic de coupe : tout bord d'audio porte son micro-fade) ; le **crossfade** (X) entre deux événements qui se chevauchent ; le **gain d'événement** (la poignée du milieu : ±dB sans toucher au fader — l'équilibrage local avant la console) ; et **Bounce Selection** (consolider des éditions en un fichier propre — le cousin audio du Render).

### 4. Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Musical Mode sur un mauvais tempo détecté | l'audio « suit » n'importe quoi | vérifier/corriger le tempo détecté AVANT de cocher |
| VariAudio sur de la polyphonie | des segments fantaisistes | monophonique strict ; la polyphonie, c'est l'oreille (l25 M1) |
| Pitch Snap 100 % | la voix morte, l'auto-tune involontaire | corriger vers, jamais jusqu'à |
| Coupes sans fades | clics à chaque bord | le micro-fade est un réflexe, pas une option |

### La mission (m10-e13, PROUVÉE — la plus rusée du module)

Le produit fournit un audio : un thème **fredonné** (voix, 8 mesures, volontairement approximatif — l'asset « le fredon du réal », 30 s, à produire avec « La Remise »). Mission : Musical Mode, VariAudio, Extract MIDI, **relecture et correction** de l'extraction (les octaves fausses, les segments doublés), puis soumission du MIDI corrigé. Le moteur compare à la mélodie-cible connue : `samePitchSequenceAsGiven` en tolérance (≥ 90 % de la séquence) — *tu es noté sur ta relecture d'extraction, la compétence réelle du métier*.

- [ ] Musical Mode : l'audio élastique — tempo détecté vérifié, ±10 % sans douleur
- [ ] VariAudio : corriger vers (jamais jusqu'à) ; Extract MIDI = le fredon devient partition-brouillon
- [ ] Fades partout, gain d'événement avant le fader
- [ ] L'extraction se relit note à note — c'est la relecture qui est le métier

### Pourquoi la livraison est une compétence

Une musique n'existe professionnellement que livrée — au bon format, au bon niveau, découpée comme le mixeur du film l'attend. C'est ici que trois investissements du module paient d'un coup : les groupes de l07 (tu vas comprendre leur vraie raison d'être), le headroom de l08, et l'hygiène de l01. La livraison ratée est le cliché du débutant talentueux ; cette leçon l'élimine.

### 1. L'Export Audio Mixdown : les réglages qui comptent

La fenêtre (File → Export → Audio Mixdown) et ses cinq décisions :

| Réglage | Valeur de livraison | Pourquoi |
|---|---|---|
| Plage | les **locators** sur le cue exact — ou le cycle marker du cue (l12 : ils resservent) | le silence de tête/queue se règle ici, pas au montage |
| Format | WAV, **24 bits, 48 kHz** (le monde de l'image) | le MP3 est une courtoisie d'écoute, jamais un master |
| Canaux | Stereo Out (interleaved) | — |
| Niveau | les crêtes du fichier ≤ **−1 dB**, sans limiteur qui écrase | le headroom de l08 §1 rend ça naturel : le tutti à −6 laisse la place |
| Nommage | `Projet_Cue03_v2_MIX.wav` dans `Exports/` | l01 : le futur toi est un inconnu pressé — et la prod reçoit dix cues de dix compositeurs |

Et le **Real-Time Export** : coché si des instruments externes ou des plugins capricieux l'exigent ; sinon l'offline est fiable et rapide.

### 2. Les stems : la vraie raison d'être des groupes

Le **stem** est un mixdown partiel : les cordes seules, les cuivres seuls, les synthés seuls — le film final se mixe avec TES familles séparées, pour que le mixeur du film puisse baisser les cuivres sous le dialogue sans toucher à tes cordes. La demande standard : **un stem par groupe de l07** — et voilà pourquoi l'architecture en familles n'était pas de l'ordre pour l'ordre :

```
La méthode Cubase : Export Audio Mixdown → section Channel Selection →
coche les GROUPES (GRP Strings, GRP Winds, GRP Brass, GRP Perc?…,
GRP Synths) → "Multiple" : UN export, N fichiers, mêmes locators
La loi des stems : la somme des stems = le mix. Donc :
  - les FX Channels (reverbs !) doivent être routés OU exportés en
    stem propre ("GRP + ses sends" : l'option qui inclut les départs)
  - AUCUN traitement sur le master pendant l'export des stems (le
    limiteur du master s'appliquerait N fois — une fois par stem)
Le test de vérité : réimporte les stems dans un projet vide, aligne,
somme : compare au mix. Identique ? livrable. Différent ? cherche le
send orphelin ou le master sale.
```

### 3. Le colis de livraison (la check-list du métier)

Ce qu'une livraison professionnelle contient — et que la mission fait assembler :

```
Exports/Livraison_Cue03_v2/
├── Cue03_v2_MIX.wav               le mix référence
├── Stems/                          un par famille, mêmes locators
├── Cue03_v2_MIDI.mid              le MIDI complet (le mixeur ou le
│                                   copiste peuvent en avoir besoin —
│                                   et la macro PREP de l09 l'a nettoyé)
├── Cue03_notes.txt                tempo(s), tonalité, timecode IN/OUT,
│                                   frame rate, versions de montage
└── (le .cpr archivé via Back up Project — chez toi, pas dans le colis)
```

### 4. Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Exporter « ce qui joue » sans locators | trois secondes de silence, la queue de reverb coupée | les locators sur le cue, la reverb qui finit DANS la plage |
| Le MP3 comme livrable | la prod re-demande, tu as l'air amateur | WAV 24/48 ; le MP3 en plus, jamais à la place |
| Stems avec le limiteur master | la somme ≠ le mix, le mixeur du film t'appelle | master nu pendant les stems ; le test de la somme |
| Les reverbs orphelines | des stems secs, l'espace perdu | sends inclus ou stem FX dédié |
| « final_MIX_new2.wav » | personne ne sait quoi mixer | versionné, daté, dans Livraison_ |

### La mission (m10-e14, GUIDÉE)

Le colis complet sur ta maquette de l08 : mix (locators, −1 dB), 3 stems par groupes (test de la somme en `verifyHint` : « réimporte, somme, compare — null test à l'oreille »), MIDI nettoyé par PREP, notes.txt rédigé. Checklist 11 étapes — déclarative, mais chaque étape porte son auto-contrôle : c'est le niveau 3 (§30.1) en régime de croisière.

- [ ] WAV 24/48, crêtes −1 dB, locators justes, reverb incluse
- [ ] Un stem par groupe, master nu, la somme = le mix (le test de vérité)
- [ ] Le colis : mix + stems + MIDI propre + notes — nommé pour un inconnu pressé
- [ ] Les groupes de l07 étaient les stems de l14 : rien n'était décoratif

## 34.3 LEÇON m10-l15 — « Synthèse : la session complète — "La Remise" »

```mdx
---
id: m10-l15-synthese

title: "Synthèse : la session complète — composer, produire, livrer « La Remise »"
estMinutes: 40
skills: { daw_workflow: 0.5, melody: 0.2, harmony: 0.2, orchestration: 0.1 }
---
```

### Pourquoi finir par une session, pas par une leçon

Quatorze leçons t'ont donné les gestes ; la quinzième les enchaîne **dans l'ordre où le métier les enchaîne**. « La Remise » (l12) attend sa musique : cette leçon est le déroulé commenté de la session complète — et sa mission est le capstone du module, la plus grande mission prouvée du produit. Il n'y a presque rien de neuf ici ; il y a l'essentiel : **la chronologie**.

### 1. Le déroulé de la session (la chronologie du métier)

```
PHASE 0 — LA NAISSANCE (l01, l02)                              ~10 min
  Projet depuis le template Sketch, 48/24, frame rate de la vidéo,
  Root Key posée après le spotting (elle en découle !), Ctrl+Alt+S.

PHASE 1 — LE SPOTTING (l12)                                    ~20 min
  Import vidéo, vérifications de naissance, deux visionnages muets,
  markers : IN 0'04" / bascule 1 (curiosité→inquiétude) 0'31" /
  HIT porte 1'02"0 / bascule 2 (la découverte) 1'08" / OUT 1'26".
  → le spotting DICTE le brief : "curiosité qui s'assombrit, un hit,
    une révélation qui ne résout pas" — mode mineur à ambiguïté
    (m02-l12), la vis douce (m09-l04) vers le hit, et l'OUT en
    non-résolution : le Module 9 entre dans Cubase.

PHASE 2 — LE SQUELETTE TEMPOREL (l11, l12)                     ~15 min
  Tempo naturel de la scène (♩≈72), la mesure sur le HIT par la
  méthode manuelle (§4 de l12 : 72 → 73.5 et le temps 1 tombe),
  Signature Track si la bascule 2 veut sa mesure d'extension.
  LE TEMPS D'ABORD, LES NOTES ENSUITE — la leçon la plus
  contre-intuitive du métier, et la plus rentable.

PHASE 3 — LA COMPOSITION (tout M1/M2/M9 — dans le Key Editor, l03)
  L'esquisse au piano du template (l10 M5 : en pensant les cibles),
  le motif de la curiosité (m02-l02 : un archétype "pas" chromatisé ?),
  la vis vers le hit, l'accord de la découverte (le m(maj7) de
  m09-l03 ? le dim7 de l13 M1 ? — TON choix, argumenté dans les notes).
  Iterative 60 % sur le jeu, dur sur les ostinatos (l03).

PHASE 4 — L'ORCHESTRATION ET LA VIE (l04, l05, M5)             
  Les rôles distribués sur le template (celli chalumeau?… celli ou
  clarinette chalumeau pour la curiosité — les fiches décident),
  les Expression Maps posées, PUIS la passe de CC1 à la molette,
  ligne par ligne, en dirigeant (l04 §2 — jamais l'inverse).

PHASE 5 — L'ÉQUILIBRE (l07, l08)                               ~20 min
  Le câblage est déjà dans le template ; la méthode des 6 étapes,
  le test mono, les deux profondeurs. Freeze des pistes stables (l10).

PHASE 6 — LA LIVRAISON (l14)                                   ~15 min
  Le colis complet : mix, stems, MIDI (PREP ! — l09), notes.txt.
  Back up Project. La session est close, retrouvable, transmissible.
```

Relis les minutages : **la musique elle-même n'est qu'une phase sur six** — et les cinq autres sont ce qui la rend possible, juste, et livrée. C'est la proportion réelle du métier ; ce module existait pour elle.

### 2. Les trois disciplines transversales (le récapitulatif du module en trois lignes)

1. **L'intendance est créative** : le template, le nommage, le versioning ne sont pas de l'administration — ils sont la condition matérielle de la spontanéité (l01, l02, l06, l09) ;
2. **La vie s'écrit** : CC1, articulations, tempo — trois pistes invisibles qui portent plus d'émotion que les notes (l04, l05, l11) ;
3. **On livre ce qu'on a câblé** : les familles de l07 étaient les stems de l14 ; le headroom de l08 était le −1 dB final ; rien n'était décoratif (l07, l08, l10, l14).

### 3. La mission capstone (m10-e15, PROUVÉE — la grande)

La session complète sur « La Remise », en trois soumissions échelonnées (le format bi-parts de m02-e30, étendu à trois) :

```
PART 1 — LE SPOTTING (déclaratif + guidé)
  La table de markers exportée (CSV) : IN/OUT, hit, bascules,
  descriptions rédigées. Vérification : les timecodes attendus ±1 s
  (le produit connaît sa vidéo), les descriptions non vides.

PART 2 — LA MUSIQUE (prouvée — le MIDI complet)
  Le MIDI multi-pistes de la session, PREP appliqué. Le moteur analyse :
  tonalité à ambiguïté contrôlée OU mineur assumé (variantes),
  un motif développé (findMotifs), la dérive OU l'épaississement vers
  le hit (tensionCurve sur la fenêtre 0'31"–1'02"), l'OUT non résolu
  (la contrainte forbiddenCadences en fin — m09-l04 en checker),
  les registres des instruments déclarés (orch.range-violation),
  la présence de CC1 vivant (les checkers de l04),
  et les événements de tempo (le hit : la mesure qui tombe — le
  checker tempoEvents de l11 croisé au timecode : LA vérification
  signature du module).
PART 3 — LA LIVRAISON (déclarative outillée)
  La checklist du colis (l14), notes.txt inclus.
```

XP majeur (400), badge de module — et le rapport de la Part 2 est le plus complet que le produit sache produire : mélodie, harmonie, orchestration, expression, temps et image, jugés ensemble pour la première fois. *C'est la promesse du brief — « le site guide, analyse et corrige » un travail fait dans Cubase — tenue littéralement.*

- [ ] La chronologie : naissance → spotting → temps → notes → vie → équilibre → colis
- [ ] La musique est une phase sur six — les cinq autres la rendent possible
- [ ] Les trois disciplines : l'intendance créative, la vie qui s'écrit, on livre ce qu'on a câblé
- [ ] « La Remise » est livrée : le module est dans mes mains, plus dans mes notes
