## 37.1 LEÇON m06-l07 — « Keys : Rhodes, FM, lo-fi — l'intimité électrique »

```mdx
---
id: m06-l07-keys
module: module-06-sound-design
title: "Keys : Rhodes, FM, lo-fi — l'intimité électrique"
estMinutes: 20
skills: { sound_design: 0.7, harmony: 0.3 }
---
```

### Pourquoi les keys sont l'humain de l'hybride

Entre le pad (le monde) et le lead (la voix), il manque quelqu'un : **l'instrument qu'une personne joue** — attaque au doigt, accords qui respirent, imperfection assumée. C'est le rôle des keys : le piano électrique et ses descendants. Au cinéma, les keys signent l'*intimité contemporaine* — la scène d'appartement, la confidence, le souvenir récent (là où le piano acoustique dit le souvenir ancien, l10 M5 : la goutte). Trois fiches, un métier.

### 1. La famille RHODES : le velours électrique

| Rubrique | Contenu |
|---|---|
| Recette | samples de piano électrique OU synthèse : sinus + un partiel cloché (la « tine »), ADSR percussif-long (A 0, D long, S bas, R moyen), la velocity → brillance (frappe douce = rond, frappe forte = le « bark » qui mord) |
| Vie (l02) | trémolo/auto-pan LENT (le vibrato stéréo du Rhodes historique : LFO 0.5–3 Hz → pan) — sa signature |
| Caractère | chaud, rond, nocturne — le velours qui a vécu |
| Bande utile | 100 Hz–5k : un habitant du bas-médium (l03 : il NÉGOCIE avec le pad et le growl — dans un stack dense, high-pass à 150 et le Rhodes garde son âme) |
| Écriture | accords enrichis de M1 l17–l18 : le Rhodes est FAIT pour les 7es et les 9es (Cmaj9, m11 — les tensions y sonnent crémeuses là où le piano les durcit) ; voicings resserrés main droite, la basse laissée au sub |
| Territoire | le jazz urbain, le néo-noir moderne (m09-l03 : le remplaçant contemporain du piano-goutte), l'amour discret |
| Mariage | + contrebasse pizz + texture vinyl = le trio noir contemporain ; + cordes sourdines = la ballade de générique |

### 2. La famille FM : le cristal électrique

| Rubrique | Contenu |
|---|---|
| Recette | synthèse FM (un oscillateur module la *fréquence* d'un autre — pas besoin de la théorie complète : les presets « E.Piano FM » des synthés modernes) ; attaque cliquante, corps vitreux, velocity → l'éclat |
| Caractère | brillant, précis, un peu froid — les années 80 au sens noble, redevenues contemporaines |
| Bande utile | 200 Hz–8k, présence marquée : il perce naturellement là où le Rhodes se fond |
| Territoire | la nostalgie synthétique, la mélancolie néon, le drame rétro-moderne |
| Mariage | + pad analog (le chaud sous le froid : le contraste de l04 §3 en duo standard) ; + sub simple |
| Le choix Rhodes/FM | même partition, deux époques : le Rhodes dit « la nuit chaude », le FM dit « la nuit froide » — c'est un choix de température, donc de scène |

### 3. La famille LO-FI : la mémoire dégradée

| Rubrique | Contenu |
|---|---|
| Recette | n'importe quelles keys (Rhodes, FM, piano) **passées à la dégradation** : wow/flutter (le pitch qui ondule comme une bande usée — LFO lent irrégulier → pitch, ± 5–20 cents), filtrage passe-bas prononcé, bruit de bande/vinyl intégré, parfois bitcrush léger |
| Caractère | voilé, instable, aimé-mais-abîmé — le souvenir qui se dégrade en direct |
| Vie | la dégradation EST la vie : le wow compte comme motion (`sd.static-stack` créditée d'office) |
| Territoire | la mémoire, le deuil doux, l'enfance perdue — LE son du drame indé contemporain |
| Mariage | + texture vinyl assortie (l05 : la texture et l'instrument racontent la même bande) ; attention au **pléonasme** : keys lo-fi + texture + atmosphère toutes dégradées = le pathos de brocante — UNE couche porte la dégradation, les autres restent propres |

### 4. Écrire pour les keys (le pont M1)

Les keys sont l'instrument-harmonie de l'hybride : c'est par elles que tes acquis M1 entrent dans le monde synthétique. Trois réflexes :

```
1. Les voicings de l17-l18 s'appliquent tels quels — et MIEUX :
   les tensions crémeuses du Rhodes tolèrent des empilements que
   le piano durcit (la 9 et la 11 côte à côte : oui)
2. La basse aux autres : main gauche minimale ou absente — le sub
   (l06) et le Rhodes se partagent le travail que le pianiste
   faisait seul (deux Layers, deux rôles : la leçon l03 en acte)
3. La respiration du joueur : les keys se JOUENT (m10-l03 :
   Iterative 60 %, jamais de quantize dur) — un Rhodes quantisé
   dur est un FM qui s'ignore
```

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Le Rhodes plein registre, basse comprise | la guerre du bas-médium (l03) | main droite resserrée, la basse au sub |
| Le pléonasme lo-fi | tout est abîmé, rien n'est touchant | UNE couche dégradée, le reste propre |
| Quantize dur sur les keys | l'humain retiré de l'instrument-humain | Iterative 60 % — les keys sont un JEU |
| FM et Rhodes empilés | deux époques qui se disputent | un choix de température par scène |

### La mission (m06-e07, LAYERING + notes)

La progression de m09-l01 §1 (la romance : `Cmaj7 | Am7 | Fadd9 | G7sus4-G7` puis le iv) réalisée aux keys : choisis la famille selon le brief tiré (« la confidence tard le soir » / « le souvenir qui s'efface »), voicings enrichis main droite (≥ 3 accords à tensions), sub séparé en couche dédiée, motion signature déclarée (trémolo Rhodes ou wow lo-fi). Le moteur vérifie : les voicings (tensions présentes, `guideToneVoicing` assoupli F-4), la séparation des rôles (keys sans notes < C3, sub monophonique), la famille cohérente au brief, le jeu non quantisé dur (`quantizeInfo`).

- [ ] Rhodes = la nuit chaude, FM = la nuit froide, lo-fi = la mémoire qui se dégrade
- [ ] Les tensions de M1 sonnent crémeuses ici : les keys sont l'harmonie de l'hybride
- [ ] La basse au sub, la main droite resserrée — deux couches, deux rôles
- [ ] Une seule couche dégradée par stack ; les keys se jouent, ne se quantisent pas

## 37.2 LEÇON m06-l08 — « Leads : mono, poly, supersaw — la voix synthétique »

```mdx
---
id: m06-l08-leads
module: module-06-sound-design
title: "Leads : mono, poly, supersaw — la voix synthétique"
estMinutes: 25
skills: { sound_design: 0.6, melody: 0.4 }
---
```

### Pourquoi le lead est un chanteur

Le lead est la couche `melodic` du modèle (l03) : celle qui porte LA ligne. Et tout ce que le Module 2 t'a appris s'applique à lui *sans remise* — motif, contour, prosodie, ambiances : un lead ne rachète jamais une mélodie faible. Ce que cette leçon ajoute : les trois morphologies du chanteur synthétique, et les gestes qui font qu'une ligne de synthé *chante* au lieu de biper.

### 1. La famille MONO : le soliste

| Rubrique | Contenu |
|---|---|
| Recette | 1–2 oscillateurs (saw ou carré), **mode monophonique** + legato + **glide** (l06 §3 : 30–80 ms sur les notes liées) ; filtre expressif (velocity ou molette → cutoff) |
| Le geste-clé | le glide sélectif : lié = glisse, détaché = attaque nette — la ligne acquiert un *phrasé* (le legato/staccato de m10-l05, version synthèse) |
| Vie | vibrato RETARDÉ (LFO 5–6 Hz → pitch, delay 300–600 ms : la note se pose PUIS vibre — la règle du corniste, l02 §5, ici vitale) |
| Caractère | incarné, vocal, un individu — le seul lead qui « respire » |
| Territoire | la mélodie exposée, le thème de personnage électronique, la SF intime |
| Écriture | tout m02 : le mono-lead est un chanteur — ambitus raisonnable, respirations écrites (des silences ! le legato perpétuel épuise, l06 M2), le climax tenu qui vibre |

### 2. La famille POLY : le chœur de synthé

| Rubrique | Contenu |
|---|---|
| Recette | le même type de son en polyphonie, attaque un peu plus douce, PAS de glide (le glide polyphonique = la bouillie de sirènes) |
| Métier | les lignes harmonisées (la mélodie en tierces/sixtes — les II sous les I, l02 M5 version synthé) et les accords-mélodies (le hook d'accords) |
| Frontière avec le pad | l'ADSR : le poly-lead attaque et articule (profil soutenu), le pad se lève (profil nappe) — même matière parfois, deux existences (l01 §3 : l'ADSR EST le rôle) |
| Territoire | le rétro assumé, l'élan pop, l'action lumineuse |

### 3. La famille SUPERSAW : la voix massifiée

| Rubrique | Contenu |
|---|---|
| Recette | 5–7 saws désaccordées largement (± 15–40 cents) + spread stéréo — l'unisson géant |
| Caractère | énorme, brillant, euphorique — un stade qui chante |
| Le danger structurel | le supersaw mange TOUT : large (il occupe la stéréo), dense (il occupe 200 Hz–15k), désaccordé (il floute la hauteur). C'est un tutti à lui seul |
| Les trois disciplines | **high-pass sévère** (200–300 Hz : le bas au sub, sinon `sd.band-pileup` immédiat) ; **la largeur se paie** : s'il est large, le reste se resserre (l12 formalisera le budget stéréo) ; **réservé aux sommets** — le supersaw permanent est un ff permanent (l10 M1 : plus de crescendo possible) |
| Territoire | le climax épique-électronique, la libération, le générique qui décolle |
| Jumeau orchestral | le tutti cuivres+cordes de m09-l02 palier 4 — même fonction, même règle d'économie |

### 4. Faire chanter (les gestes transversaux)

```
1. LA COURBE AVANT LE SON : joue ta ligne au piano d'abord (m10-l02 :
   le Sketch) — si elle ne chante pas nue, aucun supersaw ne la sauvera
2. LE PITCH EST EXPRESSIF : le vibrato retardé, le glide sélectif,
   et le BEND d'approche (la note prise 1/2 ton dessous, glissée —
   l'appoggiature du synthé, l22 M1 en molette)
3. LE FILTRE SUIT LA PHRASE : cutoff mappé sur la molette et JOUÉ
   (m10-l04 §2 : la deuxième passe, en dirigeant) — l'arche de phrase
   au timbre : ta tensionCurve rendue audible
4. LA PLACE : le lead vit dans le médium-présence (500 Hz–5k dégagés
   pour lui — l03 : le registre se RÉSERVE, comme pour toute mélodie,
   orch.masking version Hz)
```

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Vibrato dès l'attaque | le synthé-chèvre (l02 — récidive fréquente ici) | delay de LFO : pose, puis vibre |
| Glide en polyphonie | les sirènes | le glide est mono, sélectif, dosé |
| Supersaw du début à la fin | le climax permanent, donc aucun | réservé aux sommets ; le mono porte les couplets |
| Le lead qui bipe | mélodie faible maquillée en gros son | m02 d'abord : la ligne nue au piano, le test des trois écoutes |
| Le lead noyé | `sd.band-pileup` dans le médium | 500 Hz–5k réservés : les pads se poussent |

### La mission (m06-e08, LAYERING + notes — la plus mélodique du module)

Ton thème de m02-e30 part 2 (TON personnage) porté au lead : choisis la morphologie (mono/poly/supersaw — argumente au brief), déclare glide/vibrato/filtre en `motion` et champs dédiés, pose le stack minimal dessous (un body high-passé, un sub). Le moteur vérifie : la ligne inchangée (ton capstone M2 re-reconnu par `findMotifs` — la continuité du curriculum en un checker), le lead en bande réservée et les autres couches hors de sa bande (le dégagement mesuré), vibrato déclaré avec delay > 200 ms si mono, et les règles `sd.*` muettes. *Ton personnage a maintenant une voix électrique — la version orchestrale attendra M7.*

- [ ] Mono = le soliste (glide sélectif, vibrato retardé), poly = le chœur, supersaw = le stade
- [ ] Le supersaw est un tutti : high-pass sévère, largeur payée, sommets seulement
- [ ] Un lead ne rachète jamais une mélodie faible — m02 d'abord, le son ensuite
- [ ] 500 Hz–5k dégagés : le registre du chanteur se réserve

## 37.3 LEÇON m06-l09 — « Plucks et arps : le mouvement écrit »

```mdx
---
id: m06-l09-plucks-arps
module: module-06-sound-design
title: "Plucks et arps : le mouvement écrit"
estMinutes: 25
skills: { sound_design: 0.5, rhythm: 0.5 }
---
```

### Pourquoi le mouvement s'écrit aussi en notes

La leçon l02 a donné trois moteurs de vie (LFO, enveloppe, automation) ; en voici un quatrième, le plus musical : **le mouvement en notes** — la couche `movement` du modèle jouée note à note. Le pluck en est l'instrument, l'arp en est l'écriture, et l'ostinato de m09-l02 (« il ne varie pas : il recrute ») en est la dramaturgie. Cette leçon ferme aussi une promesse de l01 : le release se calibre enfin au tempo, chiffres à l'appui.

### 1. Le pluck : la goutte synthétique

| Rubrique | Contenu |
|---|---|
| Recette | saw ou carré + **enveloppe de filtre percussive** (l02 §3 : cutoff qui s'ouvre à l'attaque et se referme vite — le « pluck » est un geste de filtre plus que d'ampli), volume-ADSR : A 0, D 100–400 ms, S 0, R selon tempo (§3) |
| Caractère | net, perlé, précis — la goutte qui rebondit |
| Bande | attaque riche (2k–8k : c'est un habitant naturel du `top`, l03) sur un corps discret |
| Vie | la velocity VARIÉE (la hiérarchie métrique de l08 M1 dans les frappes — un pattern de plucks à velocity constante est une boîte à rythme triste) et le delay synchronisé (l12 : son partenaire de toujours) |
| Jumeau orchestral | le pizzicato (l02/l04 M5) — même métier : la ponctuation, le pouls discret |

### 2. L'arp : l'accord déplié dans le temps

L'arpégiateur joue les notes tenues une à une selon un pattern — mais **l'arp écrit à la main vaut presque toujours mieux** que l'arpégiateur : tu contrôles le contour (m02-l05 !), les appuis, les respirations. L'arpégiateur sert l'exploration (trouve le pattern) ; le Key Editor le fixe (possède-le). Les paramètres qui font le sens :

```
DIRECTION     up = l'élan | down = la retombée | up-down = la vague
              (les silhouettes de m02-l05, en miniature)
OCTAVES       1 = le pouls discret | 2-3 = le mouvement qui scintille
              (chaque octave ajoutée éclaircit ET agrandit)
VITESSE       1/8 = la marche | 1/16 = la course | triolets = la houle
              — SYNC toujours (l02 §2 : le mouvement rythmique se
              synchronise, sans exception ici)
GATE          la durée relative des notes : court (30-50 %) = perlé,
              nerveux | long (80-100 %) = coulé, liquide
```

Et la loi harmonique, héritée en droite ligne de M1 : **l'arp expose l'accord note à note** — un voicing médiocre s'entend DAVANTAGE arpégé que plaqué (chaque note passe seule au premier plan). Tes accords enrichis de l17–l18 sont le matériau : l'arp sur Cmaj9 scintille, l'arp sur une triade nue tourne à vide au bout de deux mesures.

### 3. Le release et le tempo : la promesse chiffrée de l01

La traîne d'un pluck/arp se calibre sur la grille — voici la table :

```
À ♩ = 120 :  une croche = 250 ms, une double = 125 ms
RÈGLE :      release ≈ la durée d'un pas de l'arp (le son meurt quand
             le suivant naît : le legato perlé)
             release < un demi-pas : le staccato sec (chaque note isolée)
             release > deux pas : le lavis (les notes se fondent —
             beau à 1 octave, boueux à 3)
LE RÉFLEXE : le tempo change ? le release se recalcule. (Et le delay
             sync de l12 suivra tout seul, lui.)
```

C'est la version synthèse d'une loi que tu connais : la reverb du néo-noir se calibrait au tempo des silences (m09-l03) — **toute traîne est une décision rythmique**.

### 4. L'ostinato synthétique : la dramaturgie du pattern

L'arp qui tourne EST l'ostinato de m09 — mêmes lois, mêmes pouvoirs :

| Loi (m09-l02/l04) | Traduction arp |
|---|---|
| « il ne varie pas : il recrute » | le pattern reste, on ajoute : une octave, un pluck doublé, le gate qui s'allonge — le crescendo d'arp est un crescendo d'épaisseur |
| la dérive de l'étau (m09-l04) | UN paramètre glisse : le cutoff qui s'ouvre sur 16 mesures, le gate qui se resserre — la vis, version filtre |
| l'asymétrie qui boite | le pattern de 3 notes sur une grille de 4 double-croches : le motif tourne contre la mesure et retombe sur ses pieds tous les 3 temps (le 3-contre-4 hypnotique — l'hémiole de l09 M1 automatisée) |
| l'interruption-apnée | l'arp qui se TAIT un temps avant la bascule : le silence de m10-l12 §4, ici en une note muette |

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| L'arpégiateur laissé en pilote | le pattern générique, aucun contour | explore à l'arpégiateur, fixe au Key Editor |
| Velocity constante | la boîte à rythme triste | la hiérarchie métrique dans les frappes (l08 M1) |
| Release ignoré au changement de tempo | le lavis surprise (ou le sec surprise) | la table §3 : release ≈ un pas |
| L'arp sur triade nue, 32 mesures | le tourniquet vide | le matériau de l17–l18 : l'arp expose le voicing |
| L'arp qui varie ses notes sans cesse | le moteur qui bégaie (m09-l02, récidive) | le pattern tient ; l'épaisseur et les paramètres bougent |

### La mission (m06-e09, LAYERING + notes — la plus rythmique du module)

16 mesures de tension montante (brief : « la filature qui se resserre », ♩=110) : un arp écrit à la main (pattern de 3 notes sur grille 1/16 — l'asymétrie §4), velocity hiérarchisée, UNE dérive déclarée (cutoff ou gate en automation), un pluck de ponctuation (velocity variée, release calibré — déclare ton calcul), sub discret, et l'apnée : l'arp se tait 1 temps à la mesure 13. Le moteur vérifie : le pattern constant en hauteurs (`motifType: rhythmic` recyclé), la dérive présente (`motion` + la logique `requireChromaticDrift` adaptée au paramètre), la hiérarchie de velocity (corrélation velocity×poids métrique — le checker de `prosodyPlan` recyclé), le silence de la mesure 13, et le release déclaré cohérent avec le tempo (±30 %).

- [ ] Le pluck est un geste de filtre ; sa velocity porte la hiérarchie métrique
- [ ] L'arp s'explore à l'arpégiateur et se possède au Key Editor
- [ ] Release ≈ un pas de l'arp — toute traîne est une décision rythmique
- [ ] L'arp est un ostinato : il recrute, il dérive, il boite, il s'interrompt — il ne bégaie pas
