# SECTION 29.4 — LES QUIZ DU MODULE 5 (ORCHESTRATION, l01–l10)

**Périmètre.** Les dix leçons livrées du Module 5 (mode d'emploi + neuf fiches) déclarent leurs `QuizBlock` ; §29.2 a déjà livré **m05-l08 (clarinette)** comme quiz-type « de fiche ». Ce lot livre les **9 quiz restants (44 items)** : l01 (4 questions) et l02–l07, l09, l10 (5 chacune).

**Adaptation de la charte au format fiche** (dans la lignée du quiz l08 de §29.2, qui ne comportait pas de question `play`) : le lecteur audio du produit ne rend pas les timbres — or le cœur d'une fiche EST le timbre. Les questions `play` ne sont donc utilisées que là où la hauteur et l'espacement démontrent acoustiquement le point (registre grave, `orch.low-interval-limit`) ; partout ailleurs, les items testent la connaissance opérationnelle de la fiche, distracteurs tirés des tables « Erreurs fréquentes (détectées) ». La question intégrative finale croise systématiquement le Module 1 ou une fiche antérieure — le module étant lui-même un réseau de renvois (« elle vaut d'être lue des deux côtés »).
