# SECTION 62 — MODULE 12 : LA BANQUE DE SONS — LE MODULE-RESSOURCE

## 62.1 Positionnement — le module qui n'est pas un module

M12 est d'une autre nature : **pas un parcours, une ressource transversale** — la bibliothèque de référence que les onze autres modules citent et que l'élève consulte à la demande. Son contenu existe déjà aux trois quarts (les fiches M5, le bestiaire M6, les tables M7/M8) : M12 l'**indexe, le complète et l'outille**. Trois composantes :

```
1. LE LEXIQUE DES FICHES (l'index unifié) : toutes les fiches
   d'instruments (M5 + les pupitres V1), les familles de patchs (M6),
   les alliages (M7), les sections (M8) — UN point d'entrée,
   cherchable, filtrable (par registre, par rôle, par émotion :
   "je cherche un porteur de mélancolie au ténor" → celli, cor
   anglais, chalumeau, Rhodes sombre)
2. LA SONOTHÈQUE DE RÉFÉRENCE (l'audio du produit) : chaque fiche
   armée de ses exemples SONORES (les registres joués, les alliages
   A/B, les articulations) — produits en interne (bibliothèques
   orchestrales du studio + synthés : zéro problème de droits),
   le chantier d'assets le plus volumineux du produit (~400 clips
   de 5-15 s, spécifiés par les fiches elles-mêmes)
3. LE GUIDE D'ÉQUIPEMENT (le pont vers le réel) : les catégories
   de bibliothèques et d'outils du métier (orchestre échantillonné,
   synthés, percussions, voix) — en CATÉGORIES et critères de choix,
   jamais en marques imposées (la neutralité commerciale : on
   enseigne à choisir, on ne vend pas) — plus les gabarits :
   le template 3 tailles (m10-l02) pré-câblé par catégories
```

**Format produit** : pas de leçons numérotées — des **pages de référence** (le kind existant `REFERENCE`, consommé par les liens des leçons) + un exercice transversal unique : le **défi de la palette** (generator : « trouve dans le lexique trois porteurs pour [émotion × registre] » — l'entraînement au réflexe de casting, rejouable à l'infini). Volumétrie : ~30 pages de référence (dont 21 fiches existantes ré-indexées + 9 nouvelles : les pupitres V1 — trombone, tuba, basson, timbales/percussions, harpe, chœur — et 3 pages de guide).

**Décision d'architecture** (la dernière du curriculum) : M12 n'a **pas de badge ni de progression** — il est ouvert dès M5 et ne se « termine » pas : la banque est un lieu, pas un trajet (la leçon du modal, appliquée au produit lui-même).
