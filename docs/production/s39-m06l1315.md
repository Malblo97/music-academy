# SECTION 39 — MODULE 6, LEÇONS 13–15 : LE LOT FINAL

## 39.1 LEÇON m06-l13 — « La tenue du son : saturation, compression, sidechain »

```mdx
---
id: m06-l13-tenue
module: module-06-sound-design
title: "La tenue du son : saturation, compression, sidechain"
estMinutes: 25
skills: { sound_design: 0.8, rhythm: 0.2 }
---
```

### Pourquoi trois traitements de plus (et pas dix)

m10-l08 t'a interdit presque tous les traitements — et sa règle d'or tient (*l'écriture avant le fader*). Mais le monde synthétique a une différence de nature : **ses sons n'ont pas de corps** — pas de bois qui vibre, pas de cuivre qui sature naturellement, pas de section qui se cimente en jouant ensemble. Les trois outils de cette leçon fabriquent ce corps manquant : la saturation donne la chair, la compression donne le liant, le sidechain donne… autre chose — un geste rythmique à part entière, le seul traitement de tout le cursus qui soit aussi une écriture.

### 1. La saturation : la chair

La saturation ajoute des harmoniques en « écrêtant » doucement le signal — c'est la distorsion apprivoisée, et c'est LE traitement du monde synthétique :

| Dose | Effet | Usage |
|---|---|---|
| **Légère** (drive à peine engagé) | le son « prend corps » : +2 dB de présence perçue sans +2 dB réels | quasi universelle sur les couches synthétiques principales — le body, le growl (l06 : promis), le lead |
| **Moyenne** | le grain audible, la chaleur qui mord | le growl fâché du thriller, les keys lo-fi (l07), le caractère |
| **Lourde** | la matière transformée | le braam (l10 : promis aussi), les FX — c'est de la sculpture (l11), plus du traitement |

Deux lois d'application : **la saturation s'applique par couche, jamais sur le stack entier** (saturer le mix = la boue harmonique : chaque couche sature SA bande) ; et **le sub ne sature qu'exprès** — saturer le sub crée des harmoniques au-dessus de 90 Hz, c'est-à-dire un growl involontaire qui envahit le bas-médium (l03) : soit c'est le but (la basse hybride en UNE couche : légitime, déclare alors la vraie bande), soit c'est une fuite.

### 2. La compression : le liant (la version synthétique de la doctrine)

m10-l08 §3 t'a donné la doctrine orchestrale (un seul, doux, sur le groupe — le CC1 fait le reste). Le monde synthétique la module en deux points :

```
CE QUI NE CHANGE PAS : pas de compression par couche "pour le punch" —
  l'enveloppe ADSR (l01) fait au synthé ce que le CC1 fait à l'orchestre :
  si le pluck manque de punch, c'est son decay, pas un compresseur
CE QUI CHANGE : le GLUE de stack — un compresseur doux (2:1, 1-2 dB de
  réduction, attaque lente 30 ms, release auto) sur le BUS des couches
  synthétiques soude le stack en un instrument : les couches de l03
  cessent d'être des voisines et deviennent un corps. C'est le liant
  que les sections orchestrales ont par nature (l'acoustique partagée)
  et que le synthétique doit fabriquer.
```

Le réglage qui compte : **l'attaque lente** (20–30 ms) laisse passer les transitoires (les attaques des plucks, la définition) et ne comprime que la tenue — le glue cimente sans écraser. L'attaque rapide, elle, mange les transitoires : c'est un autre outil (le nivellement), rarement le tien.

### 3. Le sidechain : le traitement qui est une écriture

Le sidechain fait baisser une couche **quand une autre joue** : le compresseur écoute la source (le kick, le sub, l'impact) et « pompe » la cible (le pad, le body). Né du mixage (faire de la place), il est devenu un **geste rythmique** — la respiration du stack :

| Usage | Recette | Effet |
|---|---|---|
| **Le nettoyage** (l'origine) | le sub sidechaine le body/pad : 2–4 dB de creux à chaque note de basse, release rapide | le grave reste lisible sans EQ — la négociation de place de l03, automatisée |
| **Le pompage rythmique** | la source est un kick fantôme (une piste muette qui bat la pulsation !) ; le pad pompe 4–8 dB, release calé au tempo (l09 §3 : encore la loi des traînes) | le stack ENTIER respire sur le pouls — l'ostinato sans notes : le mouvement de l02, fabriqué par le creux |
| **La bascule dramatique** | l'impact (l10) sidechaine tout le stack : 1 coup = tout s'efface 1 seconde puis remonte | le choc qui fait le silence — l'apnée de m09-l04, automatisée |

Le champ `sidechainedBy` du modèle (§35.1) déclare ces liens — et le rapport les lit comme des relations : « ton pad respire sur ton sub » est une phrase d'analyse, pas de mixage. Jumeau orchestral du pompage : il n'en a pas — c'est le premier geste de tout le cursus qui n'existe QUE dans le monde synthétique. Note-le : tu viens de franchir la frontière où l'hybride cesse d'imiter l'orchestre et devient lui-même (l14 est la porte à côté).

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Saturer le stack entier | la boue harmonique | par couche, chacune sa bande |
| Le sub saturé sans le savoir | un growl fantôme dans le bas-médium | le sub reste pur — ou la saturation est déclarée (bande élargie) |
| Compresser chaque couche « pour le punch » | l'ADSR contredite par son traitement | le punch est dans le decay ; le glue est sur le bus |
| Le pompage sur tout, tout le temps | la mer malade — le tic de production des années 2010 | le sidechain est un geste : rythmique assumé, ou nettoyage discret (2–4 dB), pas un état du monde |
| Le release de pompage non calé | la respiration qui boite contre le tempo | release ≈ le pas du pouls (la table de l09 §3 sert une troisième fois) |

### La mission (m06-e13, LAYERING)

Reprends ton stack de basse hybride (m06-e06) + un pad body : déclare la saturation du growl (dose, bande résultante élargie honnêtement), le glue de bus (champ dédié du stack), et DEUX sidechains — le nettoyage (sub → pad, 2–4 dB) et le pompage rythmique (kick fantôme → body, release calé : déclare ton calcul au tempo). Le moteur vérifie : la cohérence bande×saturation (growl saturé → `band.high` ≥ 800), les liens `sidechainedBy` non circulaires (checker trivial), le release déclaré ±30 % du pas, et `sd.sub-conflict` toujours muette (le growl saturé ne doit pas redescendre sous 90).

- [ ] Saturation = la chair, par couche et par bande — le sub reste pur ou se déclare
- [ ] Le glue de bus soude le stack ; le punch vit dans l'ADSR, pas dans un compresseur
- [ ] Le sidechain est une écriture : nettoyage, pompage calé, ou apnée automatisée
- [ ] Premier geste sans jumeau orchestral : l'hybride commence à parler sa propre langue

## 39.2 LEÇON m06-l14 — « L'hybride : marier le synthétique et l'orchestre »

```mdx
---
id: m06-l14-hybride
module: module-06-sound-design
title: "L'hybride : marier le synthétique et l'orchestre"
estMinutes: 30
skills: { sound_design: 0.5, orchestration: 0.5 }
---
```

### Pourquoi c'est la leçon-somme du duo M5/M6

Tout le cursus convergeait ici : le Module 5 t'a donné l'orchestre, ce module t'a donné la synthèse, et le son du cinéma contemporain est leur mariage — pas leur addition. La différence entre les deux est LA leçon : **l'addition empile deux mondes qui se battent ; le mariage distribue les rôles entre deux mondes qui se complètent**. Trois protocoles couvrent le métier, plus les lois de cohabitation déjà semées (l04, l05, l06) et récoltées ici.

### 1. La loi fondamentale : un rôle, un monde

Reprends la table des rôles de l03 (sub/body/top/texture/movement/fx/melodic) : le mariage hybride se décide **rôle par rôle** — pour chaque rôle, UN des deux mondes est titulaire, l'autre est absent ou renfort discret. Les distributions canoniques :

```
L'ORCHESTRE HABILLÉ (le drame contemporain)
  melodic: orchestre (celli, cor)     body: PAD analog sous les cordes
  sub: SYNTHÉ (le sub que les Cb      texture: SYNTHÉ (le grain)
       n'ont pas — il commence OÙ     top/mvt/fx: selon la scène
       elles s'arrêtent : ~40 Hz)
  → l'orchestre sonne "plus grand que lui-même" sans qu'on entende
    de synthé : l'hybride invisible — 70 % du métier

LA MACHINE HUMANISÉE (le thriller techno, la SF)
  melodic: LEAD ou keys               body: pads
  movement: arps (l09)                sub: synthé
  … et L'ORCHESTRE en renforts : un vrai pupitre de celli sous le
  pad (la chair que le synthé n'a pas), des cors réels sur le braam
  → la machine qui a un cœur : l'inverse exact, mêmes lois

LE DUEL (la dramaturgie par les mondes)
  les deux mondes ENTIERS, mais JAMAIS en même temps : la scène A
  est orchestrale, la scène B synthétique — le passage de témoin
  de l06 §3 étendu à tout le spectre : le changement de monde EST
  la bascule (le héros entre dans la matrice ; le souvenir devient
  présent). La médiante chromatique du timbre.
```

### 2. Les trois protocoles de fusion (quand les mondes se touchent)

Quand un rôle est partagé (le renfort discret), trois techniques font la couture invisible :

| Protocole | Recette | Le pourquoi |
|---|---|---|
| **La doublure fantôme** | le pad joue LES MÊMES notes que les cordes, 6–9 dB dessous, high-passé à 150 (l04 §1 : le mariage analog+sordino) | l'oreille fusionne les timbres qui bougent ensemble (la loi de toute doublure, M5) — le pad devient la « résonance » des cordes |
| **Le fantôme granulaire** | les celli rendus (m10-l10) → granulaire (l11, recette 1) → le drone-fantôme SOUS les celli réels qui jouent | la matière est LA MÊME : la fusion est parfaite par construction — et l'étrangeté affleure (« on reconnaît sans savoir », 4e occurrence : c'est le principe directeur du module) |
| **Le relais d'enveloppe** | le synthé porte l'attaque (pluck, impact), l'orchestre porte la tenue (les cordes enflent DANS la queue du pluck — l'inverse du pré-écho) | chaque monde donne ce qu'il fait le mieux : le transitoire parfait du synthé, la tenue vivante de l'archet (le piano de l10 M5 rêvait de ce relais) |

### 3. Les lois de cohabitation (la récolte)

Les arbitrages semés au fil du module, réunis en table de référence :

| Territoire | La loi | Source |
|---|---|---|
| Le sub (< 90 Hz) | UN roi : sub synthé OU contrebasses — le passage de témoin est un geste de mise en scène | l06 §3, `sd.sub-conflict` |
| Le bas-médium (120–350) | le monde titulaire du body y règne ; l'autre se high-passe | l03 §1, l04 §6 |
| Le médium mélodique | le titulaire du rôle `melodic` a sa bande réservée — l'autre monde s'y tait (`orch.masking` et sa version Hz, même loi) | l08 §4 |
| L'espace | l'orchestre vit dans SA salle (Room/Hall de m10-l08), le synthétique peut être HORS-LIEU (sec, ou dans un espace impossible : le shimmer) — **la différence d'espace est un axe dramatique** : le réel a une salle, l'irréel n'en a pas | l12 §1 |
| Le temps | l'orchestre respire (rubato, m10-l11), la machine est exacte — leur écart de quantisation est un CHOIX : serré = fusion, lâche = duel | m10-l03 §2 |

### 4. L'erreur-mère et son antidote

L'erreur-mère de l'hybride : **le doublage total** — tout l'orchestre doublé par tout le synthé, « pour la puissance ». Résultat : la bouillie riche, aucun monde lisible, `sd.band-pileup` sur tout le spectre. L'antidote tient en une question, à poser rôle par rôle : *qu'est-ce que ce monde apporte que l'autre n'a pas ?* — le sub que les contrebasses n'ont pas, la chair que le pad n'a pas, l'exactitude que l'archet n'a pas, la respiration que la machine n'a pas. Si la réponse est « rien », le renfort dégage (le test du mute de l03 §3, appliqué aux mondes entiers).

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Le doublage total | la bouillie riche | un rôle, un monde titulaire — la question de l'apport |
| Le pad qui commence à 50 Hz sous les Cb | la guerre du royaume, version hybride | la distribution : le sub synthé commence OÙ l'orchestre s'arrête |
| Les deux mondes dans la même reverb par défaut | l'irréel banalisé | la différence d'espace est un axe : décide-la |
| Le synthé quantisé dur sous un orchestre rubato | la couture qui s'entend à chaque mesure | l'écart de quantisation est un choix — serré ou assumé |
| L'hybride visible partout | le procédé qui devient le sujet | 70 % du métier est l'hybride INVISIBLE : l'orchestre plus grand que lui-même |

### La mission (m06-e14, LAYERING + notes — la répétition générale)

« L'orchestre habillé » sur le thème de m05-e08 (le thème héroïque orchestré) : reprends ton orchestration, ajoute le stack d'habillage — sub relais (départ à 40 Hz, `given` : les Cb tiennent jusqu'à E1), pad fantôme (mêmes notes que tes cordes, −6 dB min, high-pass 150), texture, et UN protocole de fusion déclaré (fantôme granulaire tracé à un rendu, OU relais d'enveloppe sur le climax). Le moteur vérifie : les notes du pad ⊆ notes des cordes (la doublure fantôme en checker — comparaison de pitch-class sets par fenêtre), les bandes du relais sub/Cb sans chevauchement, le niveau relatif, la traçabilité de la source granulaire, et l'ensemble `sd.*` + `orch.*` muets ensemble — **la première soumission jugée par les deux registres de règles à la fois**.

- [ ] Un rôle, un monde titulaire — et la question de l'apport pour tout renfort
- [ ] Trois protocoles : doublure fantôme, fantôme granulaire, relais d'enveloppe
- [ ] Les cinq lois de cohabitation : sub, bas-médium, mélodie, espace, temps
- [ ] 70 % du métier est invisible : l'orchestre plus grand que lui-même

## 39.3 LEÇON m06-l15 — « Synthèse : la scène hybride complète »

```mdx
---
id: m06-l15-synthese
module: module-06-sound-design
title: "Synthèse : la scène hybride complète"
estMinutes: 35
skills: { sound_design: 0.6, orchestration: 0.2, harmony: 0.1, melody: 0.1 }
---
```

### Pourquoi finir par une scène, pas par un stack

Quatorze leçons t'ont donné un bestiaire et des lois ; la quinzième les fait servir une **dramaturgie** — car un stack n'existe qu'au service d'une scène qui bouge. Le déroulé ci-dessous est la méthode de conception d'une scène hybride complète, du brief au stack final ; sa mission est le capstone LAYERING du produit, la plus grande soumission déclarative du cursus.

### 1. La méthode (la chronologie du sound designer-compositeur)

```
1. LE BRIEF → LA DISTRIBUTION DES MONDES (l14 §1)
   Avant toute note : qui est titulaire de quoi ? L'orchestre habillé,
   la machine humanisée, le duel ? — la décision la plus structurante
   de la scène se prend sans toucher un synthé.
2. LE SPOTTING DES BASCULES (m10-l12, ou les bascules du brief écrit)
   → chaque bascule reçoit son geste : phrase de ponctuation (l10),
   changement de lieu (l12), passage de témoin (l06/l14), ouverture
   de largeur (l12) — la dramaturgie est un plan d'événements d'espace
   et de matière autant que de notes.
3. LE STACK DE CROISIÈRE (l03 : body → sub → top → vie → soustraction)
   L'état stable de la scène — 3-4 couches actives, réglementaires.
4. LES COUCHES JOUÉES (l07-l09) : qui porte l'harmonie, la ligne,
   le mouvement — et leurs motions.
5. LA TENUE (l13) : saturations par couche, le glue, les sidechains
   déclarés.
6. LA MISE EN SCÈNE (l12) : les trois coordonnées de chaque couche —
   le tableau de la scène sonore, rempli.
7. LA SOUSTRACTION FINALE (l03 §3, étape 5 — toujours la dernière) :
   le test du mute sur la scène entière ; le champ `removed` documenté.
```

### 2. Le capstone (m06-e15, LAYERING tri-parts — la grande soumission)

Le brief : **« La Remise » — la version hybride.** La scène que tu as spottée (m10-e12) et composée pour orchestre (m10-e15) se réécrit en score hybride — même vidéo, mêmes bascules, autre monde sonore. Trois parts (le format de m10-e15) :

```
PART 1 — LA DISTRIBUTION (déclarative argumentée)
  Le plan des mondes : pour chacun des 7 rôles, le titulaire et le
  pourquoi (champ libre par rôle) ; le plan des bascules : quel geste
  à 0'31", 1'02", 1'08" (ponctuation / lieu / témoin / largeur).
  Vérification : complétude, cohérence déclarée (un rôle sans titulaire
  = sd.role-coverage en amont).
PART 2 — LE STACK COMPLET (le LayerStack intégral)
  8 à 14 couches sur la durée de la scène : le stack de croisière,
  les couches jouées (notes incluses — l'harmonie de la scène re-jugée
  par M1, la ligne par M2), les FX événementiels calés aux bascules
  (cibles en ticks × timecode), les sidechains, les trois coordonnées
  de chaque couche. Le moteur déroule TOUT : sd.* au complet, la
  doublure fantôme si déclarée, les motions, la pyramide des niveaux,
  le budget stéréo, les règles mélodiques/harmoniques sur les couches
  à notes — le rapport le plus large du produit avec m10-e15.
PART 3 — LA SOUSTRACTION (le livrable d'économie)
  Le champ `removed` obligatoire et argumenté : ≥ 2 couches essayées
  puis coupées, et pourquoi. La discipline érigée en livrable noté
  (craft) : on juge aussi ce que tu as su enlever.
```

XP majeur (400), badge de module — et le diptyque m10-e15 / m06-e15 devient la pièce maîtresse du portfolio de l'élève : *la même scène, deux mondes, une seule dramaturgie* — la preuve par l'exemple que la composition précède l'instrumentarium.

### 3. Le récapitulatif du module (quinze leçons en six phrases)

- [ ] Un son se lit en trois notions : la matière, le sculpteur, l'enveloppe — et l'ADSR est le rôle (l01)
- [ ] Ce qui bouge est vivant : LFO, enveloppe, automation — trois vitesses de vie par stack (l02)
- [ ] Le layering est de l'orchestration en hertz : sept rôles, la carte du spectre, la soustraction finale (l03)
- [ ] Le bestiaire est une affaire de fiches : cinq familles de pads, l'invisible, la loi du grave, l'intimité électrique, la voix, le mouvement écrit (l04–l09)
- [ ] La ponctuation a une cible, la matière a une source, l'espace a un budget, la tenue a trois outils (l10–l13)
- [ ] L'hybride est un mariage de rôles, pas une addition de mondes — et 70 % du métier est invisible (l14–l15)
