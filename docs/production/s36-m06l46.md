# SECTION 36 — MODULE 6, LEÇONS 4–6 : LE BESTIAIRE COMMENCE

## 36.1 LEÇON m06-l04 — « Pads : les cinq familles »

```mdx
---
id: m06-l04-pads
module: module-06-sound-design
title: "Pads : les cinq familles"
estMinutes: 30
skills: { sound_design: 0.8, orchestration: 0.2 }
---
```

### Pourquoi le pad est l'instrument-roi de l'hybride

Le pad est au score hybride ce que les cordes tenues sont à l'orchestre : **le tapis** — la couche `body` par excellence (l03), celle qui porte l'harmonie pendant que tout le reste vit dessus. C'est aussi le son le plus demandé, le plus cherché dans les banques (m10-l06 : les quarante pads), et le plus mal compris : « pad » n'est pas UN son, c'est **cinq familles** aux métiers distincts. Cette leçon donne les cinq fiches — recette de synthèse, caractère, territoire, mariage orchestral — au format des fiches M5 : après elle, tu ne chercheras plus un pad, tu le *choisiras* (ou le fabriqueras).

### 1. La famille ANALOG : la chaleur

| Rubrique | Contenu |
|---|---|
| Recette | 2–3 oscillateurs **saw désaccordés** (± 5–12 cents — l'équation de l01 §1), low-pass ouvert aux 2/3, résonance discrète, ADSR nappe (A 400–900 ms, R 1–2 s) |
| Vie (l02) | LFO lent → cutoff (la respiration) ; le detune EST déjà une vie |
| Caractère | chaud, épais, enveloppant — le « vintage » au sens noble |
| Bande utile | body classique : 100–4k (high-pass à ~100 : la loi de l03) |
| Territoire | la nostalgie, le rétro-futur, la chaleur humaine dans la machine |
| Mariage orchestral | + cordes con sordino à l'unisson = le tapis hybride de base (l14 formalisera) — les deux chaleurs fusionnent sans couture |

### 2. La famille AMBIENT : l'air

| Rubrique | Contenu |
|---|---|
| Recette | matière douce (saw très filtrée, ou samples soufflés), attaque TRÈS lente (1–3 s), release longue, **beaucoup de reverb assumée** (la seule famille où `sd.wash-out` tolère — car l'ambient N'EST PAS le body principal : il se superpose) |
| Vie | LFO random lent → pan/cutoff (le scintillement, l02 §2) |
| Caractère | vaporeux, sans contour, plus un lieu qu'un son |
| Bande utile | médium-aigu : 300 Hz–10k — il vole AU-DESSUS du body, jamais à sa place |
| Territoire | l'espace, le rêve, la mémoire ; la SF contemplative (m02-l13 : l'apesanteur a trouvé son instrument) |
| Mariage | + harmoniques de violons, + flûte grave exposée (l06 M5 : le velours enfin accompagné sans être masqué) |

### 3. La famille DIGITAL : le verre

| Rubrique | Contenu |
|---|---|
| Recette | wavetables mouvantes ou FM douce, attaque moyenne, **la position de wavetable modulée** (le timbre qui se transforme EST le son) |
| Vie | l'enveloppe ou l'automation → position de table : le pad qui *devient* autre chose |
| Caractère | froid, cristallin, précis — la beauté inorganique |
| Bande utile | large avec présence marquée : 200 Hz–12k |
| Territoire | la technologie, le clinique, le merveilleux froid ; le thriller techno (m09-l04 : l'aiguille a trouvé sa version tenue) |
| Mariage | + celesta/harpe dans l'aigu ; **contraste** avec les cordes plutôt que fusion — le digital se marie par opposition (le froid contre le chaud : un axe dramatique à lui seul) |

### 4. La famille CHOIR : l'humain massifié

| Rubrique | Contenu |
|---|---|
| Recette | samples de chœur (« aah/ooh ») ou formants synthétiques ; attaque douce, PAS de vibrato individuel audible |
| Vie | crossfade de voyelles (automation lente ooh→aah = le crescendo d'ouverture vocale) |
| Caractère | sacré, ancien, humain-mais-pas-quelqu'un |
| Bande utile | le médium de la voix : 200 Hz–4k — ATTENTION : c'est la zone critique de l03, le choir se paie en place |
| Territoire | l'épique (m09-l02 : la couche « chœur¹ » du tableau, version synthétique), le sacré, la révélation |
| Mariage | + cuivres en blocs (l'épique complet) ; + cordes graves (le requiem). Piège dédié : le choir-pad sous une VRAIE voix soliste = le kitsch immédiat |

### 5. La famille HYBRID : la matière déguisée

| Rubrique | Contenu |
|---|---|
| Recette | la plus moderne : **un son acoustique rendu puis maltraité** (m10-l10 : Render in Place ouvrait cette porte) — cordes étirées, cor reversé, piano granularisé (l11 donnera les outils) — fondu avec une couche synthétique qui le stabilise |
| Vie | héritée de la matière source : le grain acoustique EST le mouvement |
| Caractère | organique-mais-étrange — on reconnaît sans reconnaître (la variation subliminale de m02-l04, appliquée au timbre !) |
| Bande utile | selon la source ; souvent riche en médium avec des aigus irréguliers |
| Territoire | LE son du cinéma contemporain : le drame moderne, la tension organique, tout ce qui doit sonner « ni orchestre ni synthé » |
| Mariage | avec l'orchestre dont il provient — la boucle parfaite : les celli jouent, leur fantôme granulaire les hante (l14 §3 en fera un procédé nommé) |

### 6. Choisir : la table de décision

```
Le brief dit…              → famille
chaleur, passé, humain       ANALOG
espace, rêve, apesanteur     AMBIENT
froid, précis, technologie   DIGITAL
sacré, vaste, ancien         CHOIR
étrange, organique, moderne  HYBRID
```

Et la règle des mélanges : **deux familles maximum par stack** (un body d'une famille + un ambient d'une autre est le duo standard) — trois familles de pads simultanées = `sd.band-pileup` garanti et l'identité perdue.

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Le pad-bouche-tout (20 Hz–20 kHz) | il ne laisse de place à rien | high-pass à 100, low-pass raisonnable : le pad est un `body`, pas le monde |
| Trois familles empilées | la bouillie luxueuse | deux max ; la 3e voix est une texture (l05), pas un pad |
| Le choir sous la voix | le kitsch | le choir remplace l'humain, il ne l'accompagne pas |
| Le pad statique 30 secondes | l'orgue (l02) | une motion, toujours — la respiration est le minimum vital |
| Chercher LE pad parfait une heure | m10-l06, la rechute | la table de décision, puis fabriquer/ajuster : 10 minutes |

### La mission (m06-e04, LAYERING)

Trois briefs courts (« la mémoire d'un été », « la salle des serveurs », « le monastère en ruine ») : pour chacun, choisis la famille (table §6), fabrique ou ajuste le pad, déclare sa couche (`role: "body"`, famille en `source`, bande, motion). Le moteur vérifie la cohérence famille↔brief (mapping déclaré dans la spec), les bandes disciplinées, et une motion par pad. *Un quatrième brief piège : « le héros se souvient » — deux familles défendables (analog/hybrid) : le rapport crédite les deux et affiche le pourquoi de chacune.*

- [ ] Cinq familles, cinq métiers : analog/ambient/digital/choir/hybrid
- [ ] Le pad est un body discipliné : high-pass à 100, deux familles max par stack
- [ ] La famille se choisit au brief — la table de décision avant la banque
- [ ] Le hybrid est le son du cinéma contemporain : l'acoustique déguisé

## 36.2 LEÇON m06-l05 — « Textures, atmosphères, drones : le grain du temps »

```mdx
---
id: m06-l05-textures
module: module-06-sound-design
title: "Textures, atmosphères, drones : le grain du temps"
estMinutes: 25
skills: { sound_design: 1.0 }
---
```

### Pourquoi ces trois-là ensemble

Le pad porte l'harmonie ; les trois objets de cette leçon portent **autre chose** : la texture porte le *grain* (la matière du temps qui passe), l'atmosphère porte le *lieu*, le drone porte la *gravité*. Aucun des trois n'est mélodique, aucun n'est vraiment harmonique — et pourtant ils font 50 % de l'émotion d'un score hybride : ce sont les couches qu'on ne remarque que quand elles manquent. Le test : coupe la texture d'une scène de drame contemporain — tout devient une démo MIDI.

### 1. La texture : le grain

**Définition de travail** : une couche à faible niveau (−12 à −20 dB sous le body), spectralement large mais *diffuse*, sans hauteur nette — du vinyl crackle, du souffle de bande, de l'air de pièce, du grain granulaire. Rôle `texture` du modèle (l03) : elle n'occupe pas une bande, elle **poudre** le spectre.

| Aspect | Règle |
|---|---|
| Niveau | à la limite de l'audible : on la SENT — le test : mute-la, le son devient « nu » ; remonte-la de 6 dB, elle devient un effet (raté) |
| Vie | LFO random ou l'irrégularité native de la matière (le crackle EST sa propre motion — `sd.static-stack` la compte) |
| Métier dramatique | l'époque (vinyl = mémoire), la matière (souffle = intimité), l'inquiétude (grain irrégulier = quelque chose vit dans le noir) |
| Jumeau orchestral | les tremolos ppp des cordes, la brume de m09-l01 — la texture est un tremolo de studio |

### 2. L'atmosphère : le lieu

L'atmosphère est une texture **référentielle** : elle évoque un espace réel ou plausible — vent, pluie lointaine, rumeur urbaine, résonance de hall. Frontière avec le sound design du film (les ambiances du monteur son) : la tienne est *musicalisée* — accordée (filtrée autour de la tonalité), rythmée (sa houle suit le tempo) ou harmonisée (une résonance qui contient l'accord). La règle de métier : **l'atmosphère musicale se place LÀ OÙ le montage son ne va pas** — vérifie ce que la scène porte déjà avant d'ajouter ta pluie à la sienne.

### 3. Le drone : la gravité

Le drone est une **note tenue érigée en monde** : une fondamentale (souvent + quinte) qui dure des minutes — la pédale de l15 M1 devenue instrument. Sa puissance est harmonique : tout ce qui se joue au-dessus se mesure à lui (le drone sur SOL transforme chaque accord en fonction de sol — c'est un centre tonal en béton).

```
Recette type :  2 couches — un sub-drone (sinus/triangle, 40–90 Hz,
                MONO : les lois de l03 s'appliquent à lui d'abord) +
                un body-drone (la même note +1 ou +2 octaves, matière
                riche : corde frottée rendue, saw filtrée, bol)
Vie :           l'automation LENTE (le drone qui s'ouvre sur 32 mesures =
                la tension qui monte sans qu'un seul accord change —
                l'étau de m09-l04, version timbre)
Piège majeur :  le drone + une basse jouée = deux occupants du royaume
                (sd.sub-conflict !) — quand le drone règne, la basse
                se tait ou monte d'une octave
```

Territoires : la menace sourde (thriller), le sacré (drone + choir), le désert (western moderne), la SF (le drone désaccordé de quelques cents contre lui-même : le battement lent comme angoisse).

### 4. L'assemblage des trois (la pyramide de l'invisible)

Le trio se superpose souvent — et sa hiérarchie de niveaux est stricte :

```
        DRONE (si la scène en veut un)   niveau : sous le body, -6 à -9
        ATMOSPHÈRE                        -9 à -15
        TEXTURE                           -12 à -20
Règle : chacun doit être INAUDIBLE comme objet, ÉVIDENT comme absence.
Le test du mute (l03 §3, étape 5) est LEUR test — c'est pour eux
qu'il a été inventé.
```

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| La texture au niveau d'un instrument | l'effet « radio cassée » non voulu | −12 dB minimum sous le body : on la sent, on ne l'écoute pas |
| L'atmosphère qui double le montage son | deux pluies, la bouillie référentielle | vérifier la scène ; musicaliser la tienne (accordée/rythmée) |
| Drone + basse active | la guerre du royaume (`sd.sub-conflict`) | un roi à la fois : la basse se tait ou monte |
| Le drone plat 3 minutes | la gravité devenue papier peint | l'automation lente : le drone est un crescendo géologique |
| Tout le trio à la fois, fort | le mur mystique | la pyramide des niveaux, et le test du mute |

### La mission (m06-e05, LAYERING)

La scène : « un couloir d'hôpital, la nuit, quelqu'un attend » (30 s de musique imaginée, 12 mesures à ♩=60). Stack demandé : un drone (2 couches, sub mono + body, automation d'ouverture déclarée), une texture, une atmosphère musicalisée (décris sa référence et sa musicalisation en champ libre) — PAS de pad, PAS de mélodie : l'exercice est de tenir une scène avec l'invisible seul. Le moteur vérifie la pyramide des niveaux (`level` décroissants texture < atmosphère < drone < 0), le sub-drone mono, les motions, et `sd.sub-conflict` sur l'ensemble.

- [ ] Texture = le grain, atmosphère = le lieu, drone = la gravité
- [ ] Inaudibles comme objets, évidents comme absences — la pyramide des niveaux
- [ ] Le drone est un centre tonal en béton : un seul roi sous 90 Hz
- [ ] L'atmosphère musicale se place là où le montage son ne va pas

## 36.3 LEÇON m06-l06 — « Les basses : sub, hybrid — la loi du grave »

```mdx
---
id: m06-l06-basses
module: module-06-sound-design
title: "Les basses : sub, hybrid — la loi du grave"
estMinutes: 25
skills: { sound_design: 0.7, harmony: 0.3 }
---
```

### Pourquoi le grave a sa propre loi

Tout le bas du spectre obéit à une physique impitoyable que tu connais déjà par morceaux : les intervalles s'y brouillent (`orch.low-interval-limit`, l12 M1), la largeur s'y annule (`sd.sub-width`), le royaume n'y tolère qu'un roi (`sd.sub-conflict`), et l'énergie y coûte plus qu'ailleurs (la moitié de la puissance d'un mix vit sous 200 Hz). La basse synthétique est l'instrument qui vit en permanence sous cette loi — cette leçon la fabrique, la fait jouer, et la marie au reste.

### 1. La basse SUB : l'assise pure

| Rubrique | Contenu |
|---|---|
| Recette | UN oscillateur sinus (ou triangle pour un soupçon de présence), AUCUN detune (le battement dans le sub = le pompage), mono strict, ADSR soutenu (A 5–15 ms, S haut, R court) |
| Bande | 30–90 Hz — et RIEN au-dessus : c'est sa définition |
| Écriture | **une note à la fois, jamais d'intervalle** (l12 M1 poussé à l'extrême : même la quinte y devient boue), lignes lentes, fondamentales des accords — le registre E1–C2 typique |
| Métier | l'assise *physique* : le sub s'adresse au corps de l'auditeur (le caisson de la salle) plus qu'à son oreille |
| Le problème qu'elle pose | invisible sur des petites enceintes — d'où la famille suivante |

### 2. La basse HYBRID : l'assise qui s'entend partout

Le sub pur disparaît sur un téléphone. La solution du métier : la basse en **deux couches solidaires** —

```
COUCHE 1 — LE SUB     sinus 30–90 Hz, mono (la fiche ci-dessus)
COUCHE 2 — LE GROWL   la MÊME ligne, +1 octave ou en doublage direct,
                       matière riche (saw filtrée, FM, ou basse
                       acoustique/rendue), bande 90–800 Hz, saturation
                       bienvenue (l13) — c'est LUI qu'on entend sur
                       les petites enceintes ; le sub, on le sent
Solidarité :           mêmes notes, même rythme, MÊME enveloppe ressentie
                       — deux haut-parleurs d'un seul instrument.
                       Dans le modèle : deux Layers, le growl porte
                       les mêmes `notes`, et la déclaration `role: sub`
                       + `role: body` les distingue proprement.
```

Le curseur expressif est le **filtre du growl** : fermé = la basse ronde et polie (drame) ; ouvert et saturé = la menace qui gronde (thriller, action) ; modulé par enveloppe = le « talk » funky ; automatisé vers l'ouverture = la basse qui se fâche avec la scène (la tensionCurve au cutoff, encore — l02 §4).

### 3. Écrire pour la basse synthétique (le pont avec tout M1)

La basse hybride hérite des métiers de la basse tout court (l12 M1 : la basse-fondations, la basse-mélodie) avec deux spécificités :

| Spécificité | Conséquence d'écriture |
|---|---|
| Elle n'a pas de sustain naturel à entretenir (pas d'archet à nourrir) | les tenues infinies sont gratuites → le danger est l'immobilité : rythmise (le pattern d'ostinato, m09-l02) ou automatise |
| Son attaque est programmable (l01) | l'attaque EST le groove : 0 ms = le punch électro ; 30–50 ms = le glissement organique ; et le **glide/portamento** (le pitch qui glisse entre notes liées) = la signature « synthé » assumée — réservé aux lignes monophoniques, dosé (50–120 ms) |
| Le registre du growl (90–800 Hz) est la zone critique de l03 | la basse hybride mange le bas-médium : les pads se high-passent d'autant (100→150 Hz si le growl est riche) — la négociation de place est permanente |

Et la règle de cohabitation orchestrale, anticipée en l05 et arbitrée pleinement en l14 : **basse synthétique OU contrebasses dans le sub — jamais les deux en même temps**. Le passage de témoin (les Cb tiennent la scène A, le sub prend la scène B) est un événement dramatique en soi : le monde acoustique cède au monde synthétique — un geste de mise en scène, pas un réglage.

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Le sub detuné « pour l'épaisseur » | le pompage lent qui rend malade | zéro detune sous 120 Hz ; l'épaisseur vit dans le growl |
| Des quintes dans le sub | la boue physique | une note à la fois — la loi de l12 M1, version extrême |
| Le growl oublié | « ma basse disparaît sur mon téléphone » | deux couches solidaires, toujours |
| Sub + contrebasses + drone | trois rois, zéro royaume | UN occupant sous 90 Hz — le passage de témoin est un geste |
| Le glide partout | la basse-sirène | mono, lié, 50–120 ms, et seulement où la ligne le chante |

### La mission (m06-e06, LAYERING + notes)

La ligne de basse fournie (8 mesures, l'ostinato de m09-e03 « le mur éolien ») à réaliser en basse hybride : deux couches solidaires (sub sinus mono + growl déclaré avec sa matière et son réglage de filtre), les `notes` identiques sur les deux, une automation d'ouverture du growl vers les mesures 7–8 (la charge). Le moteur vérifie : bandes réglementaires, sub mono et sans intervalles simultanés (`notes` monophoniques — checker trivial), solidarité des deux couches (mêmes attaques ± 10 ticks), motion présente, et `sd.sub-conflict`/`sd.sub-width` muettes. *Variante piège dans la spec : la version avec contrebasses actives dans le `given` — l'élève doit high-passer ou tacet : la cohabitation arbitrée en acte.*

- [ ] Sub = sinus, mono, une note, 30–90 Hz — et rien d'autre
- [ ] La basse hybride = deux couches solidaires : le sub qu'on sent, le growl qu'on entend
- [ ] Le filtre du growl est le curseur dramatique ; le glide est une signature dosée
- [ ] Un seul roi sous 90 Hz : synthé OU contrebasses — le passage de témoin est un geste de mise en scène
