# SECTION 83.2 — MODULE 10 : LES QUIZ EN JSON (expansion de §83.1)

**Périmètre.** Le plan compressé §83.1 fixe les 15 quiz du module (questions, réponses ✓, intégratives, items joués et captures). Cette section l'expanse au format JSON de la charte §29.2 : distracteurs tirés des tables « Erreurs fréquentes », `why` en deux phrases citant la section, intégrative en clôture.

**Deux extensions de schéma, propres au module DAW** (le sujet est la *production*, pas les notes — la notation `play` ne porte ni CC, ni tempo, ni mix) :
- `"capture"` : une question adossée à une capture d'écran Cubase (asset image référencé) ;
- `"playAsset"` : une comparaison audio A/B pré-rendue (asset audio référencé) — le ▶ du module.

**Écart assumé vs §83.1** : le plan listait 5 items pour l13, mais son `QuizBlock` déclare `questions={4}` — les items 3 et 4 du plan (extraction relue / rôle d'Extract MIDI) sont fusionnés. Total livré : **72 items** (les `QuizBlock` font foi).
