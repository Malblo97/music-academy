# SECTION 23.3 — LES EXERCICES DU MODULE 10 (m10-e01 → e15, JSON complets)

## Conventions du lot

**Le kind nouveau : `DAW_MISSION`.** Le Module 10 ne se joue pas dans le produit — il se joue dans Cubase, et le produit **guide, vérifie ou prouve**. Trois modes, déclarés dans `spec.mission.mode` :

- **`declarative`** : checklist auto-cochée par l'élève, chaque étape avec son `verifyHint` (le niveau 3 de §30.1 : le produit apprend à s'auto-contrôler) ;
- **`guided`** : checklist séquentielle affichée pas à pas dans l'UI ;
- **`proof`** : la mission se conclut par un **export MIDI soumis** — le moteur analyse le fichier (notes, CC, meta-events de tempo) via l'extension `proofSubmission`.

Les modes se combinent (`"guided+proof"`, `"declarative+proof"`).

**Champs par défaut** (omis quand identiques) :
```json
{ "spec": { "version": 1 }, "kind": "DAW_MISSION",
  "skills": { "DAW_WORKFLOW": 1.0 },
  "rubric": { "checklist": 100 },
  "isGenerated": false }
```
Le rubric `{ checklist: 100 }` est la forme des missions déclaratives/guidées ; les missions `proof` reprennent le triple correctness/constraints/craft sur l'analyse du MIDI soumis.

**Décisions de spec introduites ici** (à répercuter dans `@ma/shared`) :
1. `SkillId` gagne **`DAW_WORKFLOW`** ;
2. `spec.mission = { mode, checklist: [{ step, verifyHint? }], proofSubmission? }` ;
3. `proofSubmission` porte les **nouveaux checkers** annoncés par les leçons : `quantizeProfilePlan` (l03), `ccCoverage` / `ccPerNoteVariance` / `ccTensionCorrelation` (l04), `noNotesBelowPitch` / `durationProfileByArticulation` (l05), `minNoteTicks` / `noOverlaps` / `samePitchSequenceAsSubmission` (l09 — référence croisée vers une soumission antérieure via `sourceSubmission`), `tempoEvents` (l11), `pitchSequenceTolerance` (l13), `markerTable` (l12/l15, CSV), plus le croisement `tempoEvents × timecode` (l15). Tous sont des lectures mécaniques du fichier MIDI/CSV importé — aucune capacité d'analyse musicale nouvelle, les checkers musicaux existants (findMotifs, tensionCurve, orch.*, forbiddenCadences) sont réutilisés tels quels ;
4. **Assets à produire** (backlog V1 confirmé par le lot) : la vidéo **« La Remise »** (90 s, muette, libre de droits — e12, e15), l'audio **« le fredon du réal »** (voix, 30 s — e13), deux **PDF-missions** de notation (e03, e05), et le MIDI de « Départ » (e11 — extrait du MDX de l25 M1, déjà écrit).
