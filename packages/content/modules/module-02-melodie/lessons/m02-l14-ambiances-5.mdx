### Pourquoi ces trois ensemble

Les ambiances précédentes étaient des *émotions* ; ces trois-là sont des **idiomes** — des langages historiques avec leur vocabulaire propre. On ne les évoque pas avec des curseurs génériques : on les parle, ou on les cite. La fiche gagne donc une ligne : le *lexique* (les gestes qui signent l'idiome).

### 1. WESTERN

| Curseur | Réglage |
|---|---|
| Mode | mixolydien (LE mode western, l07 M1) ; pentatonique majeure pour les plaines |
| Lexique | quartes de fanfare détendues ; ♭7̂→1̂ ; le motif « appel du canyon » (saut d'octave + retombée) ; sifflable OBLIGATOIREMENT |
| Silhouette | arche large et lente (l'horizon) ; ou l'appel isolé + silence (le duel) |
| Prosodie | pointée détendue (le pas du cheval : 6/8 ou shuffle) ; ou déclamatoire à silences dramatiques |
| Tempo/registre | 70–100 balancé ; médium franc |
| Tension (gabarit `western`, nouveau) | arche très aplatie, sommet modeste à 60 % — la dignité tranquille ; version « duel » : plateau bas + UN pic tardif |

Le test de l'idiome : **la sifflabilité** — un thème western qui ne se siffle pas n'en est pas un (ambitus ≤ 9e, conjoint + quartes, prosodie simple). Piège : le western est un majeur SANS sensible appuyée (♭7̂ mixolydien) — une cadence V7→I trop scolaire le déguise en hymne.

### 2. NÉO-NOIR (la mélodie — l'harmonie vit en m09-l03)

| Curseur | Réglage |
|---|---|
| Mode | mineur à m(maj7) implicite ; chromatismes de line cliché (l22 M1/l42) |
| Lexique | **fragments inachevés** (2–4 notes qui s'interrompent) ; la blue note effleurée ; le demi-ton descendant final qui ne conclut pas ; silences plus longs que les phrases |
| Silhouette | fragments descendants épars — PAS de silhouette continue : la mélodie néo-noir est une ruine de mélodie |
| Prosodie | suspendue, croches inégales subliminales (le swing fantôme, m09-l03 §3) |
| Tempo/registre | 50–70 ; UNE voix isolée dans son registre (l'instrumentation de m09-l03 : trompette bouchée, ténor) |
| Tension (gabarit `ambiguous_dark`, en table) | ondulation moyenne sans résolution — déjà calibré |

La mécanique : le néo-noir mélodique applique l06 en négatif — **les silences sont la phrase, les notes sont la ponctuation**. Compose d'abord tes silences (où la solitude respire), puis pose 3–4 notes dedans. Piège : la phrase complète — dès que ta ligne fait 4 mesures continues et chantables, tu as écrit une ballade triste (l10), pas du noir.

### 3. JAZZ (la mélodie de type standard/ballade)

| Curseur | Réglage |
|---|---|
| Mode | majeur/mineur à tensions habitées (l18 M1 : les étrangères institutionnalisées) |
| Lexique | approches chromatiques et enclosures (l22 M1 §2) ; viser 3, 7, 9, 13 des accords (guide tones étendus, l08 §2) ; anticipations d'une croche (la mélodie arrive AVANT l'accord) |
| Silhouette | arches souples à sommets sur tensions (le climax sur la 9, pas sur la tonique) |
| Prosodie | suspendue à syncopes systématiques : fenêtre 0.35–0.7 (§7.8) — le temps fort est l'exception |
| Tempo/registre | ballade 60–80 / medium 100–140 ; médium chantant |
| Tension (gabarit `jazz_ballad`, nouveau) | arche douce dont les pics tombent sur les tensions harmoniques (couplage tensionCurve×harmonie maximal : le seul gabarit où le terme `dissonance` domine) |

La mécanique : la mélodie de jazz est une **conversation avec la grille** (le protocole B de l08 poussé à sa perfection) — chaque note se définit par ce qu'elle est POUR l'accord du moment. Piège : les tensions plaquées sans les résolutions internes — la 9 se chante parce qu'elle descend vers la fondamentale ou monte vers la tierce ; une mélodie « toute en tensions » sans conduite est une fausse sophistication (le débutant enrichi de l18 M1, version mélodique).
