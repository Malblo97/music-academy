### Pourquoi l'attente est ton vrai matériau

Une mélodie ne se joue pas dans les notes : elle se joue dans **ce que l'auditeur attend** entre les notes. Toute la boîte à outils du module converge ici : la répétition crée l'attente, la variation la déjoue, la silhouette la dirige, la respiration la suspend. Cette leçon systématise le mécanisme — c'est la version mélodique de la tension/résolution (l14 M1), et le modèle mental derrière `tensionCurve` (le terme `surprise` de §10.2 mesure exactement cela).

### 1. Les trois réponses à une attente

Chaque fois que tu as installé un pattern (motif ×2, séquence, silhouette), l'auditeur prédit la suite. Tu as trois réponses, et leur dosage EST ton style :

```
CONFIRMER    donner ce qui est attendu     → satisfaction, ancrage (≈ 60 %)
DÉVIER       donner PRESQUE ce qui est     → l'intérêt : la note plus haute
             attendu                          que prévu, le rythme décalé (≈ 30 %)
ROMPRE       donner tout autre chose        → l'événement : à réserver
                                              aux articulations (≈ 10 %)
```

Les pourcentages sont le calibrage « musique narrative » ; le thriller monte DÉVIER, l'avant-garde monte ROMPRE. La faute universelle des débutants : trop de ROMPRE (par peur d'ennuyer) — alors que **l'auditeur veut avoir raison la plupart du temps** : c'est la condition pour que ses rares défaites le ravissent.

### 2. La déviation calibrée : le catalogue

L'art fin est dans DÉVIER — donner *presque*. Cinq déviations classées par intensité :

| Déviation | Mécanisme | Effet |
|---|---|---|
| Le retard | la note attendue arrive, un demi-temps tard | micro-suspension, rubato écrit |
| L'anticipation | elle arrive tôt (la syncope de l09 M1) | élan, impatience |
| Le dépassement | la séquence devait monter d'un degré : elle monte d'une tierce | la générosité, le « plus que promis » |
| Le sous-régime | le climax préparé arrive... piano (le subito de l10 M1, version mélodique) | l'intimité inattendue — bouleversant bien placé |
| La note voisine | LA note attendue... à un demi-ton (souvent l'emprunt : ♭6̂ pour 6̂, l21 M1) | le sourire qui se voile |

### 3. La surprise a un coût (et un remboursement)

Toute rupture dépense le capital de confiance : après elle, **reconfirme** (répète la surprise pour l'intégrer au contrat — la surprise répétée devient le nouveau pattern — ou reviens au motif d'origine comme terre ferme). La rupture jamais réintégrée s'entend comme une erreur ; réintégrée, elle devient la signature. Règle du geste unique : la même surprise ne fonctionne qu'une fois par pièce — la deuxième fois, elle est une confirmation (et c'est très bien : c'est comme ça qu'on agrandit le contrat).

### Erreurs fréquentes

| Erreur | Correction |
|---|---|
| Surprendre en permanence | 60/30/10 : l'auditeur doit gagner souvent |
| Surprise jamais réintégrée | répète-la ou reviens à la terre ferme |
| Dévier avant d'avoir installé | pas de pattern = pas d'attente = pas de déviation possible |
| Le même truc trois fois | la surprise ne vaut qu'une fois ; ensuite elle est du vocabulaire |

- [ ] Confirmer / dévier / rompre — 60/30/10 en narratif
- [ ] Les cinq déviations calibrées, du retard à la note voisine
- [ ] Toute rupture se rembourse : réintégration ou retour
- [ ] Le pattern d'abord : on ne déjoue que ce qu'on a installé
