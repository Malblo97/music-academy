### Pourquoi une méthode des distances

Le jazz entre dans un film à trois distances — et confondre les distances est LA faute de goût du genre (le film sérieux ruiné par un jazz de pastiche, ou l'époque trahie par un anachronisme). Cette leçon est la méthode de dosage : *à quelle distance du jazz ta scène a-t-elle besoin d'être ?* — c'est la leçon-pont vers M9 (les genres) et la générale de tous les emplois du module.

### 1. Les trois distances

| Distance | Définition | Exigences | Emplois |
|---|---|---|---|
| **CITER** (distance zéro) | le jazz exact, souvent diégétique (le club à l'écran, la radio, le disque) | l'exactitude STYLISTIQUE ET HISTORIQUE : le sous-genre se documente (un swing 1938 n'est pas un hard bop 1958 — l'instrumentation, les voicings, le drumming datent une scène aussi sûrement qu'un costume) ; l12/l13 fournissent l'artisanat | la scène d'époque, le diégétique, le personnage-musicien |
| **STYLISER** (distance moyenne) | le langage jazz au service d'un score qui n'est pas « du jazz » : les voicings, le swing, la walking — mais la forme, la dramaturgie et le spotting du film | le tri des marqueurs : ON GARDE l'harmonie (rootless, tensions, ii-V) et le feel (swing léger, laid-back) ; ON REND la forme-chorus et le solo-performance (le film n'attend pas 3 chorus) | le crime-jazz, la comédie urbaine, le générique élégant — LE régime du métier |
| **HYBRIDER** (distance libre) | des éléments jazz DISSOUS dans un autre monde : l'accord m(maj7) dans l'orchestre (m09-l03 le faisait), le ride sous les cordes, le Rhodes dans l'électronique (m06-l07) | un ou deux marqueurs, pas plus — l'hybridation réussie est subliminale (« on reconnaît sans savoir » : le principe directeur du cursus, 5e occurrence — décidément sa loi la plus générale) | le drame contemporain, le thriller élégant, le néo-noir synthétique |

### 2. La table des marqueurs (ce qui « fait jazz », par ordre de puissance)

Pour doser une distance, il faut savoir ce qui signale — les marqueurs classés par puissance de signalement :

```
SIGNAL FORT (un seul suffit à dire "jazz") :
  le swing ternaire affirmé · la walking bass · le ride pattern ·
  la trompette bouchée/le sax ténor en solo · le scat
SIGNAL MOYEN (deux ou trois installent le climat) :
  les voicings rootless à tensions · le ii-V exposé · le comping
  syncopé · les blue notes pliées · le Rhodes
SIGNAL FAIBLE (dissous, ils colorent sans nommer) :
  le m(maj7) et le m6 · la 9 et la 13 dans les tenues · le laid-back
  léger · les approches chromatiques de basse · le quartal
LA MÉTHODE : la distance choisie DICTE l'étage de marqueurs —
  citer = tous les étages ; styliser = moyen+faible, le fort trié ;
  hybrider = faible seulement (et le signal fort en hybridation est
  précisément la faute : le ride sous l'orchestre dramatique fait
  brusquement "polar" quand la scène ne le voulait pas)
```

### 3. Les pièges de genre (l'inventaire des fautes de goût)

- **Le jazz-décoration** : le swing plaqué sur une scène qui n'en porte pas le sens (le jazz signale l'urbain, la nuit, une époque, une classe sociale — c'est un signe CHARGÉ : il dit toujours quelque chose, vérifie que c'est ce que la scène dit) ;
- **l'anachronisme** : le voicing de 1960 dans le club de 1935 — la citation se date (§1) ;
- **le pastiche involontaire** : styliser avec TOUS les marqueurs = citer sans le vouloir — et la scène bascule dans le clin d'œil ;
- **le solo qui vole la scène** : la performance là où il fallait l'ambiance (l10 §3 : la paraphrase, l'arche au spotting — le solo de film sert) ;
- **l'hybride qui s'affiche** : trois marqueurs forts « pour le style » — l'hybridation est réussie quand on ne peut plus la pointer.

### Erreurs fréquentes

| Erreur | Correction |
|---|---|
| La distance non choisie | la question AVANT la première note : citer, styliser ou hybrider ? — tout découle |
| Le signal fort en hybridation | l'étage de marqueurs suit la distance |
| La citation non documentée | le sous-genre se date : instrumentation, voicings, drumming |
| Le jazz-décoration | le jazz est un signe chargé — vérifier ce qu'il dit à CETTE scène |

### La mission (m08-e14, à variantes — les trois distances)

La même scène (« minuit, elle attend dans la voiture », 12 mesures, brief fixe) réalisée à la distance tirée : **(a) citer** — le combo exact (quartet, l13 : comping, walking, thème bouchée — les marqueurs forts assumés) ; **(b) styliser** — cordes + rythmique feutrée, l'harmonie rootless, le swing léger, PAS de solo-performance (le tri vérifié : signal fort ≤ 1) ; **(c) hybrider** — le stack M6 (pad, sub, texture) + DEUX marqueurs faibles déclarés (le m6, le laid-back — et le checker compte les signaux : fort = 0 exigé). Le rapport nomme ta distance mesurée : « 4 marqueurs moyens, 0 fort : stylisation propre — la scène reste à toi ».
