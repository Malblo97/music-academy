### Pourquoi la seconde est la dernière brique

Tierces (M1), quartes (l13)… reste la plus petite brique : la **seconde**. Empilée, elle ne produit plus un « accord » au sens d'objet à notes discernables : elle produit une **surface** — le cluster, la grappe de notes adjacentes où l'oreille cesse de compter les voix et perçoit une *matière* (dense, lumineuse, menaçante, selon la recette). C'est le point d'arrivée logique du système 3 : l'harmonie devenue pur timbre — la frontière où ce module touche le Module 6 (un cluster de cordes et une nappe de bruit filtré sont des voisins perceptifs, et le sound designer le sait : `band` et registre, même combat).

### 1. L'anatomie d'un cluster (les quatre curseurs)

| Curseur | Effet |
|---|---|
| **La brique** : secondes MAJEURES seules (le cluster « blanc »/pentatonique — doux, lumineux) vs MINEURES incluses (le cluster chromatique — âpre, serré) | c'est LE curseur douceur/morsure : do-ré-mi-sol-la (pentatonique serré) est un carillon ; do-do♯-ré-mi♭ est une lame |
| **La largeur** : 3 notes (la friction ponctuelle — l'épice) → une octave pleine (la surface) → plusieurs octaves (le mur) | de l'ornement à l'événement |
| **Le registre** : aigu = la lumière, le givre, le carillon ; médium = la présence, le voile ; grave = la menace sismique (et la boue assumée : le SEUL endroit du cursus où le low-interval-limit se viole en connaissance — le cluster grave VEUT être indiscernable) | le même cluster, trois métiers |
| **L'enveloppe** : attaqué (le choc — l'impact de m06-l10 a un cousin orchestral) vs tenu (le voile) vs **cumulatif** (les notes entrent une à une : la grappe qui pousse — le crescendo de densité, geste-roi du suspense moderne) | la dramaturgie du cluster est dans son temps |

### 2. Les trois familles d'emploi

```
LE VOILE (impressionniste) : cluster blanc/pentatonique, aigu, pp,
  tenu ou en carillon — la brume lumineuse, l'aube, la neige. Cousin
  direct du pandiatonisme (l10 : ses "clusters blancs" annoncés) —
  et souvent SUR lui : la surface posée sur le pôle
LA LAME (moderne) : chromatique, médium-aigu, dynamique mordante —
  la douleur, l'alarme, le point de rupture : le cluster-événement
  qui remplace l'accord au climax (là où même l'altéré de l09 serait
  encore "de la musique", le cluster est un cri)
LA MASSE (horreur/SF) : chromatique, grave ou TRÈS large, cumulative —
  le mur qui approche, l'irrespirable : l'octatonique (l12) articulait
  la menace ; le cluster la rend physique. Orchestralement : le divisi
  massif (chaque pupitre de cordes sur SA note — M5 : le cluster est
  l'emploi ultime du divisi) ou les cuivres bouchés en grappe
```

### 3. Les disciplines de la matière

1. **Le cluster se prépare ou se paie** : surgi de nulle part, c'est un choc (légitime — le hit de m10-l12) ; sinon il **pousse** (cumulatif) ou **se dépose** (le voile qui descend sur une harmonie claire) — l'entrée est le geste ;
2. **la sortie est une résolution de MASSE** : le cluster ne « résout » pas voix à voix (on ne les entend pas) — il se résout en bloc : il fond (les notes sortent une à une : la brume qui se lève — l'inverse du cumulatif), il s'effondre sur UN son (la grappe → l'unisson : le geste le plus puissant du répertoire moderne — douze vérités qui deviennent une), ou il s'éteint ;
3. **densité ≠ volume** : le cluster pp est plus inquiétant que ff (la masse qui chuchote) — le curseur de m06-l05 (« inaudible comme objet, évident comme absence ») s'applique au voile ; la lame, elle, frappe une fois ;
4. **au piano : l'avant-bras est une notation** (culture générale du genre — Cowell l'a écrit ainsi) ; à l'orchestre : chaque note s'écrit (le divisi se planifie, M5) ; au produit : le cluster se déclare comme verticalité large — et le moteur le tague (`cluster` : ≥ 4 notes avec ≥ 3 intervalles adjacents ≤ 2 dt) au lieu de le torturer en étiquette tertienne (le même respect d'objet que l13 §3).

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Le cluster-épice dans une pièce tonale | la tache (l01 : le piment au lieu du choix) | l'épice existe (la friction de 3 notes) mais se conduit — au-delà, on assume le système |
| Le cluster ff par défaut | la masse qui crie n'effraie qu'une fois | pp cumulatif : la masse qui chuchote |
| La sortie voix à voix | un soin inaudible | la résolution de masse : fondre, s'effondrer sur un, s'éteindre |
| Blanc/chromatique indifférenciés | le voile qui mord ou la lame qui berce | la brique est LE curseur : majeure=lumière, mineure=morsure |

### La mission (m03-e15, HARMONY_PROGRESSION)

Le triptyque de la matière, 12 mesures : **(1)** le voile — cluster pentatonique aigu déposé sur un pôle pandiatonique (l10 recyclé en socle) ; **(2)** la grappe qui pousse — cumulatif chromatique au médium, une note par temps sur 2 mesures (l'enveloppe vérifiée par les attaques échelonnées) ; **(3)** l'effondrement sur UN son — la résolution de masse vers l'unisson, tenu. Tags `cluster` (briques et largeurs vérifiées), et le rapport lit l'enveloppe : « ta grappe pousse en 8 attaques — le crescendo de densité est propre ».
