### Pourquoi le peu est plus difficile que la masse

Le tutti pardonne (la masse couvre les approximations) ; **trois instruments ne pardonnent rien** — chaque note est nue, chaque choix s'entend, chaque silence pèse. Et le métier vit de ce pôle autant que de l'autre : la scène intime, la confidence, le deuil, l'attente — la moitié d'un film se joue à moins de cinq pupitres. Cette leçon est l'anti-l07 : l'art de la soustraction orchestrale (m06-l03 §3 et m09-l03 §5 avaient posé le principe ; voici sa pratique instrumentale).

### 1. Les trois effectifs de l'intime

| Effectif | Nature | Les lois propres |
|---|---|---|
| **Le solo exposé** (1 voix + rien ou presque) | l'instrument-personnage : la confession | le choix du timbre EST tout le sens (la table §2) ; le registre expressif de la fiche se respecte au cent près (l'exposedRisk de §25.1 : ici, tout est exposé) ; l'accompagnement, s'il existe, est un souffle (une pédale, une tenue pp — jamais un tapis complet) |
| **Le duo/trio de chambre** (2–3 voix) | le tissage nu : M4 en habits d'orchestre | chaque voix passe le test du chant (l01 M4 — à trois, il n'y a QUE des solistes) ; les trois écarts de l05 deviennent vitaux ; le complément rythmique est la respiration même |
| **Le petit ensemble** (4–6) | la scène complète en miniature : tous les rôles, un pupitre chacun | la distribution de l01 à l'économie : un instrument = un rôle, zéro doublure (la doublure à cinq = un rôle sacrifié) — le quintette est un rolePlan sans filet |
| |

### 2. La table des solistes (le timbre comme casting de personnage)

Le solo exposé se choisit comme un acteur — la table croise les fiches M5 et les territoires :

```
CELLO ténor      la confession virile, le deuil digne     (m05-l04 : l'or pur —
                                                           le soliste n° 1 du drame)
VIOLON solo      la fragilité, l'âme à nu, le souvenir    (UN violon, pas la
                                                           section : l'individu
                                                           extrait de la foule)
COR              la distance, l'appel, la solitude noble  (§5.2 — le solo qui
                                                           porte un horizon)
HAUTBOIS         l'enfance, la plainte pastorale          (m05-l10 : la voix qui
                                                           parle — ET cor anglais :
                                                           l'exil, le souvenir)
CLARINETTE chalumeau  le nocturne, la confidence trouble  (m05-l12)
FLÛTE grave      le velours spectral                      (m05-l07 : le registre
                                                           inaudible en tutti —
                                                           c'est ICI qu'il vit :
                                                           l'intime est son royaume)
PIANO            la goutte, la solitude moderne           (m05-l21 — et le Rhodes
                                                           en version urbaine :
                                                           m06-l07, le jumeau)
```

La règle d'or du solo : **le soliste s'expose sur du silence organisé** — l'accompagnement de l'intime n'est pas un petit tapis : c'est un *espace* (une pédale de celli pp, une tenue d'altos, la reverb elle-même) où chaque note du soliste retombe et résonne. Le modèle mental vient du néo-noir (m09-l03 : composer les silences d'abord) — l'intime orchestral est sa généralisation.

### 3. Les gestes de l'intime (le catalogue du peu)

```
LA COUPURE (l'arrivée par contraste) : tutti → solo nu (l07 §3) — le
  geste le plus puissant du répertoire : le monde entier se tait pour
  UNE voix (la bascule d'échelle : du cosmos au visage)
L'ENTRÉE DES TÉMOINS : le solo rejoint par UNE voix (le duo qui naît :
  le contrechant de m04-l11 à effectif nu — souvent LE moment émotionnel
  de la scène : quelqu'un répond)
LE PRESQUE-RIEN : la scène tenue par une pédale + une note répétée +
  le silence (trois éléments — le stack minimal de m06-e05, version
  acoustique : l'invisible orchestral)
LA CHALEUR QUI S'APPROCHE : l'intime qui s'élargit SANS crescendo —
  une voix s'ajoute par phrase (la vague de l06 au ralenti extrême) :
  la scène qui se peuple de présences
```

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Le petit tutti | 5 instruments qui jouent comme 60 (doublures, remplissage) | un pupitre = un rôle ; la doublure n'existe pas ici |
| Le soliste accompagné d'un tapis complet | la confession sur fond de foule | l'espace, pas le tapis : une pédale, une tenue, le silence |
| Le solo dans le registre de puissance | la confession qui déclame | le registre expressif de la fiche — et ses zones risquées deviennent des couleurs (le canard du hautbois grave, exposé EXPRÈS : l'intime ose ce que le tutti interdit) |
| L'intime qui dure sans événement | la jolie attente qui s'éteint | les gestes : l'entrée du témoin, la présence qui s'ajoute — le peu a sa dramaturgie |

### La mission (m07-e08, ORCHESTRATE — le peu)

La scène intime d'Elena (le fil, toujours — après la crue de e06 et le tutti de e07 : la coupure) : 16 mesures — la coupure d'entrée (2 mesures de tutti fourni → ton solo nu : le soliste se choisit à la table §2, le choix s'argumente), le presque-rien (soliste + espace ≤ 2 éléments), l'entrée du témoin (la 2e voix, recette m04-l11 déclarée), la fin en dissolution. Contraintes : ≤ 4 parts actives, zéro doublure (le checker de l02 inversé : le tag `doubling` devient interdit), le soliste dans son registre expressif (les zones de §25.1 par part). Le rapport mesure le silence : « 31 % de ta scène est tue — l'espace organise ✓ ».
