### Pourquoi c'est la leçon-métier du module

De tout le contrepoint, le geste que tu feras le plus souvent dans ta vie de compositeur à l'image est celui-ci : **ajouter une deuxième ligne sous un thème qui existe déjà**. Le contrechant (countermelody) est ce qui sépare l'arrangement plat (thème + accords) de l'orchestration qui respire (thème + une âme qui lui répond) — le cor sous les violons de m09-l01, la réponse voilée de l'alto (m05-l03), le « second personnage » du tableau d'instrumentation romantique. Cette leçon transforme dix leçons de laboratoire en cinq recettes de pupitre.

### 1. Le contrat du contrechant (la hiérarchie assumée)

Différence fondamentale avec tout ce qui précède : les voix ne sont **pas égales** — le thème est roi, le contrechant est *premier ministre* : influent, indispensable, jamais sur le trône. Le contrat en trois clauses :

```
1. IL NE COUVRE JAMAIS : quand le thème parle, il murmure ; quand le
   thème respire, IL PARLE (le complément de l07, devenu constitution —
   le contrechant vit DANS les silences et les tenues du thème :
   cartographie-les d'abord, compose dedans ensuite)
2. IL A SA PROPRE IDENTITÉ : ce n'est ni une doublure ni du remplissage —
   c'est une mélodie (le test du chant, jusqu'au bout) avec son propre
   petit motif, plus simple que le thème (une cellule de 2-4 notes suffit)
3. IL ÉCLAIRE : il change ce qu'on entend DU THÈME (la tierce en dessous
   le réchauffe, la ligne chromatique l'inquiète, le contre-rythme
   l'énergise) — le contrechant est un adjectif
```

### 2. Les cinq recettes (le catalogue de métier)

| Recette | Mécanique | Effet / territoire |
|---|---|---|
| **La réponse** | le contrechant parle dans les respirations du thème (dialogue pur — l'imitation libre de l09 en version hiérarchique : il répond souvent avec la tête du thème) | la conversation : le duo amoureux, le mentor qui approuve |
| **Le fleuve lent** | des valeurs longues, conjointes, en mouvement contraire dominant sous le thème actif (la 1re espèce ralentie — le contrechant-cantus : les rôles du laboratoire inversés) | la profondeur : la ligne de celli qui donne au thème son gravitas (LE contrechant épique/romantique) |
| **La ligne chromatique** | le fil qui glisse par demi-tons sous le thème diatonique (l22 M1 + l05 M4 : la chaîne de retards en est la version liée) | l'ombre : l'inquiétude sous la surface, le doute du personnage — le double-fond mélodique (m03-l16 en une voix) |
| **Le contre-rythme** | la cellule rythmique complémentaire obstinée (quand le thème est en croches, lui en syncopes — l09 M1) | l'énergie : le contrechant-moteur, frère mélodique de l'ostinato |
| **Le descant** | le contrechant AU-DESSUS du thème (l'exception au registre) : une ligne planante, simple, souvent en blanches aiguës | la transcendance : le dernier refrain, l'hymne qui s'ouvre — à réserver au sommet (l'étage de m02-l05 §3 : le descant EST l'étage réservé) |

### 3. Le registre et le pupitre (le contrepoint rencontre M5)

Le contrechant vit **dans un autre registre ET un autre timbre** que le thème — les deux séparations se cumulent (la loi de m03-l16 §1 : registre, timbre, rythme — le contrechant est une superposition comme une autre) :

```
THÈME AIGU (violons, flûte, trompette)  → contrechant TÉNOR :
  celli (l'or pur de m05-l04 — LE pupitre à contrechant du métier),
  cor (la chaleur, §5.2), alto (le voilé)
THÈME MÉDIAN (cor, alto, clarinette)    → contrechant grave (celli/
  bassons) OU descant léger (flûte, violons con sordino)
LE TEST DE MIXAGE MENTAL (m10-l08 §4) : en mono, les deux lignes
  restent-elles distinctes ? — si non, le problème est registre ou
  rythme, jamais le volume
```

Et la règle de production qui découle de tout le module : **le contrechant s'écrit au piano à deux mains** (thème main droite, contrechant main gauche : si ça tient à deux mains nues, ça tiendra à l'orchestre — le piano de m05-l21, employé cette fois pour ce qu'il dit vrai : les lignes).

### Erreurs fréquentes

| Erreur | Symptôme | Correction |
|---|---|---|
| Le contrechant qui rivalise | deux thèmes, zéro hiérarchie — la bouillie noble | le contrat : il parle dans les respirations |
| La doublure déguisée | des tierces parallèles du début à la fin (une ombre, pas une voix) | son propre motif, son propre rythme — l'identité (grappes de tierces : 2–3 max, l01) |
| Le même registre que le thème | l'intermodulation, les croisements accidentels | un étage d'écart + un timbre d'écart |
| Le contrechant partout | l'adjectif sur chaque nom | il entre à la reprise (le thème nu d'abord — l'ancrage, toujours) : la 2e exposition est SA scène |

### La mission (m04-e11, COUNTERPOINT — le contrechant, l'exercice-métier)

Le thème d'Elena (m02-e30 — le retour du personnage : la continuité du curriculum) exposé nu 8 mesures, puis repris 8 mesures **avec ton contrechant** : recette déclarée (parmi les cinq — chacune a ses contraintes propres dans la variante), registre séparé (≥ une octave d'écart moyen), le complément mesuré (attaques fortes simultanées ≤ 35 %), l'identité vérifiée (`findMotifs` sur la part contrechant : sa propre cellule exigée), et le test des deux mains (la spec le dit : composé au piano, exportable tel quel). Le rapport juge la hiérarchie : « ton fleuve lent porte Elena sans jamais la couvrir — le gravitas est là ».

- [ ] Le contrat : jamais couvrir, une identité propre, éclairer — le contrechant est un adjectif
- [ ] Cinq recettes : la réponse, le fleuve lent, la ligne chromatique, le contre-rythme, le descant
- [ ] Un étage d'écart, un timbre d'écart — et le test mono tranche
- [ ] Il entre à la reprise : le thème d'abord, l'âme ensuite
